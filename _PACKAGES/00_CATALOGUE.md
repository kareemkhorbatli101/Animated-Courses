deliveries; B1 accounts, obligation, authority and how it is done here; B2 what is already
decided, the case against a half-taken decision, risk and exposure, policy versus procedure.

Their units carry model answers and self-check boxes where a task has one right answer, but there
is no appendix of answers and no separate key. **A teacher can teach from any of them as it
stands; a learner working alone cannot mark their own work.** Each affected package repeats this
notice. The key can be written from the unit source in that package's `03_Source/` — the other
thirty-nine books show the form it should take.

## 7 · How this file is organised

Each of the 17 zips beside this catalogue is a complete, self-contained package. **Unzip only the
ones you need.** The graded series has its own index inside it; every professional-book package is
laid out identically, so once you have opened one you know them all:

```
00_START-HERE.md     what the package holds, measured, and what it lacks
01_Student-Books/    the finished book(s), .docx, ready to print or teach from
02_Plans/            the adaptation plan for each book
03_Source/           one zip per book: unit source text, build scripts, QA harness
```

⚠ **The QA harness in each book is not a spell-checker.** It checks structure: that every unit has
the elements its design system requires, in the right order and the right number. That is what
holds the twin editions identical to the page, and why the counts in section 3 come out in matched
pairs rather than merely close.
