# Grammar Reference

The whole grammar of the book on a few pages. The unit number tells you where it was taught.

## Starting Point · Cause and effect in a pipe

| | |
|---|---|
| Friction **causes** a pressure drop. | cause, then effect |
| The pressure drop **is caused by** friction. | effect, then cause |
| Every meter of pipe **takes** a little. | the plain version |
| You pay for it **twice**: in the pump and in the power. | two consequences |

## Unit 1 · Scope; talking about a minimum

| | |
|---|---|
| This code **applies to** liquid pipeline systems. | what is covered |
| It **does not apply to** piping within process plants. | what is not |
| The scope **excludes** gas pipelines. | the same, in one verb |
| Pump stations **are within the scope of** this code. | one item, inside |
| **For the purposes of this code**, a terminal is … | a definition for one document |
| The code gives a **minimum**. The thickness is **at least** 7.1 millimeters. | the floor |
| Our own standard is **stricter than** the code. | more demanding, and allowed |

> **Careful:** a code states a minimum, not a value. *At least 7.1*, never *is 7.1*.

## Unit 2 · Thresholds; describing a change of kind

| | |
|---|---|
| **Below** about 2,000 the flow is laminar. | the low side |
| **Above** about 4,000 it is turbulent. | the high side |
| **Between** 2,000 **and** 4,000 it may be either. | the band |
| **Once** it becomes turbulent, the friction rises sharply. | the moment of crossing |
| It changes **at around** 2,000. · **in the region of** 2,000. | hedged |
| The two are **different in kind**, not in degree. | the strongest version |

> **Careful:** below the threshold the flow is not slightly turbulent. It is not turbulent.

## Unit 3 · Dependence; talking about an assumption

| | |
|---|---|
| The factor **depends on** the roughness. | one decides the other |
| The pressure drop **varies with** the flow rate. | changing together |
| The factor **is a function of** two inputs. | formal |
| At high flow it **is independent of** the regime. | no effect |
| The drop **is roughly proportional to** the square of the velocity. | a specific relationship |
| We **assumed** 0.045 millimeters, which **assumes** new, clean pipe. | the assumption and its condition |

> **Careful:** *depends on* and *is proportional to* are different strengths of claim.

## Unit 4 · Conditions; accumulation and surge

| | |
|---|---|
| The regime changes **depending on whether** the pipe rises or falls. | two alternatives |
| It **depends on** the gas rate, the liquid rate and the angle. | several factors |
| Use **whichever** correlation the standard names. | the one that applies |
| **According to** this method, the flow is segregated. | by a named source |
| Liquid **collects** in the low points and **accumulates** on the uphill sections. | the build-up |
| It is **swept out** ahead of the gas and arrives **as one body**. | the surge |

> **Careful:** holdup is the **fraction**, not the liquid itself.

## Unit 5 · Sufficiency

| | |
|---|---|
| There is **enough** suction head. · There is **not enough** margin. | the amount |
| The flow is **too low**. · There is **too much** friction. · **too many** bends. | beyond a limit |
| The vessel is **not high enough**. | *not* + adjective + *enough* |
| **Sufficient** margin has been demonstrated. | formal |
| The available head is **barely enough**. · **more than enough**. | just, and comfortably |

> **Careful:** *enough* and *too* never go together. Never *too enough*.

## Unit 6 · Reporting with tolerance; absence

| | |
|---|---|
| The feature is **reported as** 32 percent. · **sized at** 32 percent. | a report, not a measurement |
| **Within plus or minus** 10 percent of wall thickness. | the band |
| **At a confidence of** 80 percent. | how often the band holds |
| The depth **lies between** 22 and 42, **four times out of five**. | the whole statement |
| **No feature was reported** at that location. | what the report says |
| That **is not the same as** there being no feature there. | the correction |

> **Careful:** the absence of a report is not evidence of absence.

## Unit 7 · Prevention and protection

| | |
|---|---|
| The coating **protects** the steel **from** the soil. | *protect from* + noun |
| It **prevents** the steel **from losing** metal. | *prevent from* + *-ing* |
| It **keeps** water **out of** the gap. | *keep out of* + noun |
| Disbondment **stops** the current **reaching** the steel. | *stop* + *-ing* |
| We survey the line **to guard against** undetected loss. | *guard against* + noun |
| The lifted coating **shields** the steel **from** the current. | *shield from* + noun |

> **Careful:** *prevent* takes *-ing*, not an infinitive. Not *prevent the steel to corrode*.

## Unit 8 · Restriction; compliance over time

| | |
|---|---|
| It may be used **only if** the hardness is below the limit. | one strict condition |
| Hardness **is limited to** 22 on the Rockwell C scale. | a ceiling |
| This grade **is not permitted in** that region. | a prohibition |
| Its use **is restricted to** sweet service. | a narrowing |
| Permitted **subject to** hardness testing of the weld. | a condition attached |
| It **was compliant** in 1998 and **may no longer be**. | compliance belongs to a moment |

> **Careful:** *compliant* with no date and no environment is not a claim.

## Unit 9 · Generalization and exception

| | |
|---|---|
| **In general** the factor falls as population rises. | the usual case |
| A rural section is **typically** in the lowest class. | the usual case |
| **As a rule**, the stricter requirement applies. | conversational |
| **Except where** national rules are more stringent. | the exception |
| **Unless otherwise specified**, the standard's figure applies. | the default |
| National law is stricter here, **in which case** it applies. | the consequence |

> **Careful:** *in general* and *always* are different promises. Standards use the first.

## Unit 10 · Layered failure; arithmetic out loud

| | |
|---|---|
| **In the event that** the high alarm is missed, the high-high sounds. | a failure case |
| If the operator **fails to** respond, **in which case** the valve closes. | failure and consequence |
| **As a last resort**, the bund contains the spill. | the final layer |
| **Divide** the volume **by** the rate. That **gives** seven minutes. | the operation |
| Seven minutes **against** a measured eleven. | the comparison |
| The measured time **exceeds** the available time **by** four minutes. | the gap, with its size |

> **Careful:** if the response time is too long, the alarm is not faulty. There is not enough tank.

## Unit 11 · Joint responsibility

| | |
|---|---|
| **It was agreed that** the rate would be 1,400 cubic meters an hour. | a decision by both |
| **Both parties** confirmed the communications check. | an obligation on each |
| **Neither party may** increase the rate without the other's agreement. | a prohibition on each |
| The checklist was completed **jointly**. | done together |
| The rate **shall be agreed before** loading begins. | a requirement with timing |
| Operations may be suspended **at the request of either party**. | a right held by both |

> **Careful:** *the rate was agreed* with nobody in it is the weakest sentence in a joint record.

## Unit 12 · Undoing a nominalization

| Nominalized | Said with a verb |
|---|---|
| An investigation was undertaken. | Yusuf investigated it. |
| The implementation of a review process has commenced. | We have started reviewing it. |
| Verification of the response time was not performed. | Nobody measured the response time. |
| There was a failure of communication. | Two people did not tell each other. |
| Consideration is being given to the installation of a switch. | We are thinking about fitting a switch. |

> **Careful:** the long version is not more professional. It is longer, and the person has gone.

# The British Layer

This book is written in American English, and the switch to British English is a layer rather than a
correction. The patterns are printed in full in Book 1. The ones this book touches most are the
**-er** ending in measuring words, the **-ize** and **-yze** endings, **sulf-**, **-se** and **-ce**
in noun and verb pairs, the doubling of a single **l**, and **skeptical**, **gray** and **mold**.

**Three things never change, in either layer.**

**Standards numbers and titles.** ASME B31.4 is ASME B31.4. ISO 13623:2017 is ISO 13623:2017. A
published title is printed as its publisher printed it, including its publisher's own spelling. Two
of the documents in this book are published by bodies whose names contain spellings this layer would
otherwise change, and those names stay as their owners write them.

**Names of people, journals and institutions.** Darcy, Reynolds, Moody, Beggs, Brill. The journals
and the institutes. One of the documents in this book is published jointly by three organizations in
three countries, and all three names are printed as they print them.

**Units in a quoted figure.** Where a standard gives a hardness in Rockwell C or a pressure in pounds
per square inch, this book gives that unit, and gives the metric equivalent beside it rather than
instead of it.

**One deliberate choice, which is not a spelling layer.** Money is written with no currency symbol
anywhere in this series.

# Sources

Each unit of this book is built on one real published document. Two of the twelve are experiments
rather than documents, and both of their authors wrote plainly about what they had and had not shown.
**Read the published documents.** Reynolds and Moody are freely available and both are models of how
to describe your own limits.

| Unit | The document | What it says about its own limits |
|---|---|---|
| 1 | **ASME B31.4**, *Pipeline Transportation Systems for Liquids and Slurries*, one of the B31 Code for Pressure Piping series | It states minimum requirements for a new system. It does not cover piping within refineries and process plants, which is a different code with a lower design factor, and it does not cover gas pipelines. A hydrostatic test finds defects large enough to fail at the test pressure and proves nothing about smaller ones. The scope boundary is a judgment made once by a person on a drawing |
| 2 | Osborne Reynolds, "An experimental investigation of the circumstances which determine whether the motion of water shall be direct or sinuous…", *Philosophical Transactions of the Royal Society*, **1883** | Water, one fluid, one glass tube, a laboratory. The transition is **not a sharp line**: Reynolds found it depended on how disturbed the water was at the inlet, and laminar flow could be sustained far above the conventional figure with a very smooth entry. The two numbers in every textbook are conventions built on a real observation, not constants of nature |
| 3 | Lewis F. Moody, "Friction Factors for Pipe Flow", *Transactions of the ASME*, **1944** | A **compilation and correlation of other people's measurements**, named and credited by Moody. For circular pipe, running full, with one fluid. The published roughness values are for **new, clean** pipe, and nobody measures the roughness of a pipe in service — in the fully turbulent region, where most lines run, that unmeasured value is the only thing the answer depends on |
| 4 | H. D. Beggs and J. P. Brill, "A Study of Two-Phase Flow in Inclined Pipes", *Journal of Petroleum Technology*, **1973** | **Air and water**, in pipes of about one and one and a half inches, in a short laboratory loop, over 584 tests at a range of inclinations — which was the new and valuable part. Applying it to a twelve inch line of crude and gas at fifty bar is extrapolation, and the authors described their apparatus in detail so that readers could see how far they were going beyond it. Two accepted methods can give holdup figures that differ by a large factor |
| 5 | **API Standard 610**, *Centrifugal Pumps for Petroleum, Petrochemical and Natural Gas Industries*, published as an identical ISO standard | A **purchase specification**: it tells a manufacturer what to deliver. It says nothing about the pump you already have, its curve after fifteen years of wear, or whether the duty it was bought for still exists. The required suction head is defined at a **three percent head drop**, so a pump at exactly the required figure is already cavitating slightly |
| 6 | **API Standard 1163**, *In-line Inspection Systems Qualification*, read alongside **API RP 1160**, *Managing System Integrity for Hazardous Liquid Pipelines* | Every reported depth carries a **tolerance**, a **confidence** and a **detection threshold**; at eighty percent confidence about one feature in five may fall outside the band, and that is the specification working. **The absence of a feature from a report is not evidence of the absence of a feature from the pipe.** Verification digs are how you find out whether the tool performed on your pipe, and they are the step most often reduced |
| 7 | **NACE SP0169**, *Control of External Corrosion on Underground or Submerged Metallic Piping Systems* | It sets **criteria**, not outcomes, and gives more than one. A reading taken with the current flowing includes a voltage drop through the soil and does not describe the steel; only the polarized potential does. A reading is taken at a test post and cannot describe a square meter two hundred meters away. And a **disbonded coating shields the protective current** — the primary defense, in failing, prevents the secondary one from working, with nothing showing at the surface |
| 8 | **NACE MR0175 / ISO 15156**, *Materials for use in H2S-containing environments in oil and gas production*, in three parts | About **cracking**, not general corrosion: a compliant material can still corrode away. The environment is defined by hydrogen sulfide partial pressure, pH, chlorides and temperature, and **all four move over a field's life**, so a material correctly selected in 1998 may sit in a different region of the standard today with nobody having done anything wrong. It sets hardness limits that a welding procedure must achieve; it does not write the procedure, and it will not tell you whether your line has already cracked |
| 9 | **ISO 13623:2017**, *Petroleum and natural gas industries — Pipeline transportation systems* | It **does not override national law**, and says so: where national regulations are more stringent, those apply. It is a functional standard that says what must be achieved rather than how. The design factor follows from a **location class** and a **fluid category**, which makes it a judgment about consequences written as a decimal — and location class is assessed at a moment, while towns grow |
| 10 | **API Standard 650**, *Welded Tanks for Oil Storage*, read alongside **API RP 2350**, *Overfill Protection for Storage Tanks in Petroleum Facilities* | API 650 is about **building** the tank and not about filling it. RP 2350 treats overfill protection as a **system** including the response time and the people, and neither document tells you your own volumes, fill rate or response time. Two alarms driven from one transmitter are one layer wearing two hats, and a bund contains a consequence rather than preventing one |
| 11 | ***International Safety Guide for Oil Tankers and Terminals***, **sixth edition, 2020**, published jointly by the International Chamber of Shipping, the Oil Companies International Marine Forum and the International Association of Ports and Harbors | A **guide** published by industry bodies, not law, though much of its content appears in terminal regulations and charter terms. Almost nothing on the ship/shore checklist is information either party lacked: its purpose is to make the agreement **explicit, written and signed** by two named people. It cannot make two organizations trust each other, and it cannot make a representative who has been awake for nineteen hours read forty items carefully |
| 12 | **API Recommended Practice 1173**, *Pipeline Safety Management System Requirements*, first edition **2015** | A **voluntary recommended practice**, not a regulation, written to be **scalable**, which means it states what must be achieved and leaves the how to each organization. Its own failure mode is a documentation system growing inside it: element ten is the easiest element to do well because it can be done by writing. And it cannot make anybody care |

**Book 3's honesty core.** Eleven of the twelve units contain a failure, and **not one of the eleven is
a failure of steel**. A scope boundary nobody reviewed. A viscosity that lost its source. Six years of
pressure-drop data nobody subtracted. Three tunings of a controller that was not faulty. Eleven
mechanical seals. A blank in an inspection report. Two reports in two filing systems. A weld with no
hardness record. A village that grew beside a buried line. Seven minutes of tank and eleven minutes
of procedure. A tick where a dash belonged. Unit 12 is the published document that says the
organization is the thing that fails, and the book is arranged so that the reader reaches it having
already seen eleven proofs.

# A Note on Everything Else in This Book

**The documents above are real.** Every other named thing in this book was written for it.

**Jazira Petroleum Operations** does not exist. Neither does the **Tell Sahra** field, the **Mureij**
gathering station, the **Sahra** central processing facility or the **Mureij Training Center**. Every
person named is invented, and so is every line number, wall thickness, potential reading, inspection
feature, pump history, tank volume, checklist and self-assessment attributed to the company. The
tanker *Northern Pearl* is invented. None of it is a record of anything that happened anywhere.

**The real places are named as matters of public record only.** Deir ez-Zor, Hasakah, Homs, Banias,
the Syrian Petroleum Company, the Arab Gas Pipeline and the Kirkuk–Banias line appear because they are
facts about the country. The Starting Point describes what is publicly recorded about the two
pipelines and nothing else; **this book says nothing about their current condition, ownership,
capacity or operation.**

**This is a first-edition teaching draft.** It is not published, endorsed or approved by the Syrian
Ministry of Petroleum and Mineral Resources, by the Syrian Petroleum Company, by any other Syrian
state body, by any standards organization, professional society or industry association named in it,
or by any company. It carries no official status, and nothing in it is engineering, legal, safety,
commercial or regulatory advice.

**And the standing line.** Safety information in a language course is not a substitute for a competent
person, a procedure and a permit. This book will teach you to say *the polarized reading fails at
kilometer 9.4 and that is the section the tool could not read*. It will not tell you whether the pipe
is sound.

# At the End of the Book

Twelve units ago you could follow oil from the rock to the tank. You can now follow it along the pipe,
and — more usefully — you can read the documents that govern it and find the sentence in each one
where its own authors say what it does not cover.

You can read a scope page and find the exclusion; say what a design factor is and whose decision it
really is; explain why a dye thread breaks up and why that lets a glass tube speak about a pipeline;
work a roughness backwards from two pressure gauges; say what arrives at a separator when somebody
raises a rate; find a pump's three flows and explain eleven seals with them; put an upper bound beside
a reported depth; explain how one defense shields another underground; say why a compliant material
stops being compliant; divide a volume by a fill rate and know whether an alarm is a protection; sign
a document jointly and write a dash where a tick would be a lie; and undo a nominalization so that a
sentence has somebody in it again.

That is the whole midstream, in a language that keeps asking who, when and how do you know.

**Flowline 3 — *The Refinery and the Barrel*** begins where this book ends: at the gate of the plant
the pipeline has been feeding. It opens with a distillation test from 1921 that is still run the same
way, goes through the chemistry that turns a barrel into products people will pay for, and ends with
the number traders look at every morning and operators almost never see.

The oil does not stop at the refinery gate. Neither does this.
