# Book 1 as gapped summaries — the full plan

Every exercise in book 1 is a summary with words taken out. What changes is the **number of ways a summary can be presented**. A paragraph is one way; a sequence, a grouping, a comparison of magnitudes, a series over periods, two sides set against each other, and a web of terms are six more. Each is read differently and remembered differently. All of them are fill-in-the-blanks.

## The rule that governs everything

**A form is used only where the content already has that shape.** A grouping drawn as a flow asserts an order the chapter never states. A bar chart drawn from a table of names invents numbers. So each form has a detector, the detector either finds the shape or does not, and nothing is drawn on a guess. Where no form fits, the content is a gapped grid or a gapped paragraph.

Every number below comes from running those detectors over all eighteen chapters — the same code that builds the sheets, so the plan and the output cannot drift apart.

## The seven forms

| form | what it is for | where its content comes from | what the reader writes |
|---|---|---|---|
| **paragraph** | the argument of a stretch of prose | consecutive sentences of the section | the load-bearing words |
| **grid** | a relation with no better shape | a table of the chapter | about 45% of its cells |
| **flow** | a sequence: each stage leads to the next | a table whose rows are stages, plus the chapter’s own section order | the name of a stage, with its description left as the clue |
| **tree** | a classification: what belongs to which group | a column holding a few repeated values | the missing members |
| **chart** | magnitudes, compared by eye | a numeric column drawn to scale | the labels, read off the bar lengths |
| **graph** | a quantity moving over periods | a schedule with periods down the side or across the top | the missing periods |
| **web** | each term against what it means | the section’s own glossary | the missing terms |

The **web** is the form I chose. Vocabulary is what this exam turns on, and a web shows what a list cannot: that every term in a section hangs off one subject. Where the section states what its words mean, the web pairs term with meaning; where it does not — and half the sections do not — it pairs the English term with its Arabic, which is the thing these readers most need. It is the only added form whose source is guaranteed wherever a section has a glossary.

## Forward checks, run before the drawing code was written

### 1 — the graph detector returned zero

It looked only for periods across the header; the chapter writes its schedules with the periods down the side. Fixing that found the bond amortisation schedule in chapter 9. The graph remains rare — **one table in the whole book** — and the plan says so rather than forcing a line onto material with no periods in it.

### 2 — five chapters would have had no diagram

From its tables alone chapter 2 detected none, and 3, 5, 10 and 18 detected one. Two sources that do not depend on a table’s shape close the gap: the chapter’s own section order is a genuine sequence, so **every chapter opens on a flow of itself**, and a section’s glossary is a web, covering **45 of the 94 sections**.

### 3 — four things the detectors were drawing wrongly

Each was caught by looking at the figure rather than at the count:

- The worked January journal was drawn as a **bar chart of its row numbers** — bars labelled 1, 2, 3. A chart’s labels have to name things, not count them.
- The same journal was then drawn as a **tree grouped by date**, one "group" per date holding one row. A classification whose groups hold one member each is an index wearing a classification’s clothes.
- The four-statements table was charted on its **Chapter** column, which says chapter 5 is more than twice chapter 2.
- A gapped flow blanked the **whole card**, taking the description with it. The description is the clue: a reader who sees "enter the item in the accounts" can write *record*; a reader who sees an empty box has only the position to go on. Only the name goes now.

### 4 — two sources tested and rejected

A **bridge chart from a stated computation** ("net income was 80: revenue of 300, minus cost of goods sold of 180") would be a strong picture. Searching all eighteen chapters found such sentences in chapter 1 only, twice. Not a general source.

A **flow from ordered prose** ("first… then… finally…") appears in 14 sections across 11 chapters, but the ordinal words mark an order of explanation at least as often as an order of events, and the sentence does not say which. Drawing the wrong one asserts a process the chapter does not describe.

## The gapping rules

Carried over, because they were the part that worked:

| | |
|---|---|
| one gap per ~13 words of prose | dense enough to be work, open enough to leave text to reason from |
| 2 to 12 gaps a block, ~135 words a block | built to a word target, breaking on a sentence end |
| one spare entry a word list | a reader cannot finish by counting |
| never two gaps adjacent, never the first word | there is always readable text to work from |
| a repeated value is never gapped | the list holds it once; two slots would claim it |
| no singular against its own plural, no entry inside another | one gap with two defensible answers is worse than no gap |
| a number is never gapped in prose or a grid | recalling 300 from a list of numbers is a memory trick |
| gaps are numbered inline | marking is reading down a column |
| the section’s own vocabulary supplies the spares | a wrong answer has to be plausible |
| no instruction names a source | the sheet is used instead of the chapter, not beside it |

Five more that the diagrams need:

| | |
|---|---|
| a diagram gaps about 40% of its labels, never all | what is left is how a reader works out what is missing |
| the gap number is drawn inside the slot | a figure is an image; its gaps cannot be numbered from the margin |
| a flow never gaps two consecutive stages, and never the description | the stages either side place the missing one, and the description is the clue |
| a chart gaps labels, never bar heights | the bar is drawn to scale, so reading the length is the exercise |
| a tree never empties a group | a group with no members shows nothing about what belongs in it |

## Build-time checks

Every sheet is refused unless all of these hold:

- every sentence of the section is on some block (coverage by construction)
- every answer is in its word list; no list repeats an entry or holds one inside another
- the gap count matches the answer count, in both prose and figures
- no block opens on a gap or mid-thought
- no block is denser than one gap in seven words
- every slot drawn in a figure has exactly one answer, in gap order
- every figure renders and reports a height, so nothing is cut off
- **a sheet of four or more exercises that uses only one form is reported**
