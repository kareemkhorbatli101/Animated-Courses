# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it prevents, which is
the column worth reading twice.

## Starting Point · Forty minutes

| | |
|---|---|
| **250 words, 40 minutes, four criteria** | the forty minutes include reading the prompt |
| **a topic is a noun phrase; a position is a sentence** | *university fees* is not a position |
| **a position is a sentence somebody could disagree with** | *both sides are important* is a description of the question |
| **six minutes planning, four introduction, twenty-four body, six checking** | the last six are the cheapest marks in the paper |

## Unit 1 · Stating a position

| | |
|---|---|
| ***I would argue that* · *This essay contends that* · *On balance*** | own the claim; do not announce a discussion |
| **fees should be abolished *for first degrees*** | narrow it in the introduction so you can hold it |
| **all parts of the task = every question the prompt asks** | a two-part prompt is two tasks |
| **a clear position *throughout*** | the conclusion must be the introduction's position |

## Unit 2 · *Since*, *because*, *given that*

| | |
|---|---|
| **claim · grounds · warrant · backing · qualifier · rebuttal** | the warrant is the one nobody writes |
| ***since* and *given that* treat the reason as agreed** | *because* does not |
| ***This matters because, in general,*** | the sentence that turns three stories into an argument |
| **three facts in a sentence is plenty** | a second example is not a warrant |

## Unit 3 · *Of course*, *admittedly*

| | |
|---|---|
| **quantity · quality · relation · manner** | a reader infers from what you did not write |
| ***some* implies *not all*** | hedge where you mean to, or concede by accident |
| ***Admittedly X, but Y*** | a concession stated is stronger than one implied |
| ***of course* costs nothing; *admittedly* costs something** | know which one you are spending |

## Unit 4 · Subordination; levels

| | |
|---|---|
| **1, 2, 2, 2 is a list; 1, 2, 3, 4 is a staircase** | *extended and supported* means a drop to level 3 |
| ***one such case* · *the reason is that* · *more precisely*** | three ways down a level |
| ***another example is*** | goes along, not down |
| **the appositive, the cleft, the participle** | subordinate downwards, not sideways |

## Unit 5 · Questioning an argument

| | |
|---|---|
| **expert opinion · example · analogy · consequences · the slope** | five patterns, each with its questions |
| **in the field? inside it? reliable? agreed? evidenced?** | the five questions for an appeal to an expert |
| ***Does it follow that* · *On what evidence*** | one attacks the step, one the grounds |
| **a fallacy is a good pattern used badly** | the shape is not the error |

## Unit 6 · Concession and refutation

| | |
|---|---|
| **evidence is independent of the claim; a scenario is not** | a story of how your cause works supports nothing |
| ***It might be objected that* · *The strongest argument against this is*** | the other side at full strength |
| ***This would be decisive if*** | the conceded condition that strengthens you |
| **what would change your mind** | the sentence most candidates cannot write |

## Unit 7 · Register; nominalization

| | |
|---|---|
| **pronouns, contractions, present tense ↔ nouns, noun phrases, prepositions** | one line, not two boxes |
| ***the reduction in measured emissions*** | a clause packed into a noun phrase |
| **two or three nominalizations a paragraph** | ten costs you clarity, which is in two criteria |
| ***who did what?*** | the test of every nominalization you write |

## Unit 8 · Establishing a gap

| | |
|---|---|
| **establish a territory · establish a niche · occupy it** | wide, then narrow, then in |
| ***What is less often noticed is* · *The usual argument assumes*** | the sentence that makes an essay necessary |
| ***In this essay I will discuss both views*** | a third move with no position in it |
| **the framework describes research articles** | one move transfers; the wording does not |

## Unit 9 · Planning in language

| | |
|---|---|
| **knowledge-telling ↔ knowledge-transforming** | a plan that is your paragraphs has done no work |
| **the content space and the rhetorical space** | what do I believe; what will my reader not accept |
| ***Reader will object that X — do I believe it?*** | translation between the two |
| **put something in the plan you cannot answer** | you will answer it or concede it, and both are band 7 |

## Unit 10 · The language of a redraft

| | |
|---|---|
| **planning · translating · reviewing, interrupting each other** | not three stages passed through once |
| ***or rather* · *more precisely* · *it would be more accurate to say*** | correct forward, in words, cross nothing out |
| **re-read the last sentence; review nothing else till the paragraph ends** | word-level review is the most expensive interruption |
| ***The argument has narrowed in the course of making it*** | change the conclusion, not the evidence |

## Unit 11 · Reporting a judgment

| | |
|---|---|
| **writer · task · script · rater · scale** | five facets, and only one of them is you |
| ***tends to* · *on balance* · *would be regarded as*** | report a judgment; do not assert it |
| **a hedge with its grounds named** | *it could possibly perhaps* is vagueness, not care |
| **read the comment, not the number** | two readers who differ by half a band usually name the same fault |

## Unit 12 · Consequence; *it follows that*

| | |
|---|---|
| ***It follows that* · *The consequence is that* · *If that is right, then*** | draw the step and say it is one |
| ***It does not follow that* · *That would only follow if*** | separate the premise from the step |
| **under-representation ↔ irrelevant variance** | the two ways a test makes bad teaching rational |
| **five checks, four minutes** | position · all parts · warrants · the objection · the step |

# The British layer

This book is written in American English, and the series carries a switchable British layer: a fixed
list of words is respelled at build time. The list lives with the series rather than in this book.

**In Task 2, spelling is yours and it is marked.** Lexical Resource counts spelling, and either
system is accepted — but **not both in one essay**. Choose one and hold it for 250 words. At this
level the commonest mixed pair in this class is *organize* beside *analyze*, which is two systems in
one paragraph.

What the layer does not touch:

1. **A quoted document keeps its own spelling.** Most of this book's sources are published outside
   the United States, and their titles and quoted sentences are printed as published.
2. **A journal or publisher name keeps its published form.** *College Composition and
   Communication*, *Language Testing*, *Syntax and Semantics*, Cambridge University Press and
   Lawrence Erlbaum are citations.
3. **A technical term keeps the spelling its field uses.** *Argumentive* in Unit 6 and
   *perspicuous* in Unit 3 are the sources' own words.
4. **The date.** The month in letters in prose; the international format in data.
5. **Money has no symbol anywhere in this series.**
6. **A name is never respelled.** Toulmin, Grice, Christensen, Walton, Kuhn, Biber, Swales, Bereiter,
   Scardamalia, Flower, Hayes, Weigle and Messick are spelled as they are published.

# A note on everything else in this book

Meridian Language Center does not exist. Priya Raman, Grace Mwangi, Lars Eriksen and the eleven
students in the class were written for this book, and so was every band figure any of them is given.
Ashworth University, Calderbrook Institute of Technology, Northvale College, Harrowgate School of
Nursing and Pennine Regional Hospital are invented, and so is the band each of them is said to ask
for.

Every prompt, model paragraph, model essay, plan, marked script and realia document in this book was
written for it. No statement, question or prompt from any past examination is reproduced anywhere. The
two introductions in Unit 8, the two plans in Unit 9, the two conclusions in Unit 10, the double-marked
script in Unit 11 and the full essay in Unit 12 are all the book's own.

**Every figure attributed to "our own class" is invented** — the four criterion averages in Unit 1,
the thin-paragraph survey in Unit 2, the hedging survey in Unit 3, the two level patterns in Unit 4,
the fallacy survey in Unit 5, the four falling bars in Unit 6, the pronoun counts in Unit 7, the five
introductions in Unit 8, the five plans in Unit 9, the forty-minute timeline in Unit 10, the six
double-marked scripts in Unit 11 and the eleven practice bands in Unit 12. Each says on its face that
it is an invented class's own count, with eleven students, and several units stop to say why eleven
students cannot establish anything.

**Three charts in this book carry no numbers on purpose.** The four falling bars in Unit 6 and the
genre line in Unit 7 show an ordering and nothing more, and the timeline in Unit 10 is one invented
writer's forty minutes. Each says so in its caption, because a chart that illustrates a pattern and a
chart that reports figures are not the same object — which is Book 3's lesson, arriving here.

**Unit 12 turns the discipline on this book.** It states that a preparation book is washback, that the
task this one prepares for is a narrow slice of writing, that on the 1996 paper's own terms that is
construct under-representation, and that a book teaching four memorized paragraph shapes would raise
your band and be pure irrelevant variance. We think the slice is real and the book is defensible. We
have printed the argument against it so you can decide.

Nothing in this book is advice about your admission, registration or employment, and nothing in it is
a prediction. A practice band is what one reader thought of one essay on one afternoon.

# Closing

You began this book able to write a long essay about a subject. You end it able to state a position
somebody could disagree with, name the warrant under it, say what your hedges concede, go down a level
instead of along, ask the five questions an argument has to survive, say what would change your mind,
move a sentence along the register line, put a gap in your introduction, plan in two columns, correct
forward instead of crossing out, report a judgment without asserting it, and draw a consequence
without overdrawing it — and able to say, of every one of those, where the idea came from and what its
source does not cover.

Twelve sources, and one habit: write the objection you are afraid of.

Five sentences to take with you, one from each part of the book.

From Unit 1: **could anybody disagree with this?**

From Unit 2: **what licenses the step?**

From Unit 6: **what would change my mind?**

From Unit 9: **what will my reader not accept?**

From Unit 12: **does it follow?**
