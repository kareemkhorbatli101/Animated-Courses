# English for Cybersecurity — the sixty-row alignment

Every unit is one AI capability, one grammar point and the precision faults its
Brief Lab diagnoses. The three are chosen so that each explains the others.

## Fault ladder — labs in which each fault is diagnosed

| Fault | Labs | Repaired with |
|---|---|---|
| unscoped set | 22 | defining relative clauses and articles |
| unbounded quantity | 21 | quantifiers and stated measures |
| unstated criterion | 25 | comparatives and superlatives with a stated basis |
| undefined done | 22 | modality of requirement: shall, is to, must |
| ambiguous referent | 23 | reference, substitution and cohesion |
| missing condition | 15 | conditionals; unless, provided that, failing that |
| unstated exception | 26 | concession: although, notwithstanding, except where |
| hidden assumption | 26 | articles and attribution for given and new information |
