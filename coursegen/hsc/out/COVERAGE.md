# Coverage map — for the author, not the student

This document names the two assessments the course is built against. **Nothing
in it appears in any of the sixty units.** No unit, figure, caption, dialogue,
exercise or answer key mentions any test, awarding body or examination, and the
course contains no test technique.

Both assessments were checked in November 2026. The proficiency test was
redesigned on 21 January 2026 and the earlier format — integrated speaking and
writing tasks, long lectures, a 0–120 scale — no longer exists. This course is
built against the current design, not the one most published material still
teaches.

---

## 1 · The admissions reading-and-writing paper

Adaptive, two modules, 54 questions, four domains. The course carries all four
as ordinary school work.

|---|---|---|---|

| | | Text Structure and Purpose | B1.2 u09 *Claim, Evidence, Explanation*; B1.2 u10 *A Plan Where Every Paragraph Proves a Sentence*; the `ext` extended reading in every unit |
| | | Cross-Text Connections | B1.1 u03 *Building the Other Side First*; B1.1 u04 *Answering What Was Actually Said*; B1.2 u01 *Reporting What a Writer Actually Argued* |
| **Information and Ideas** | ~26% | Central Ideas and Details | Part 3 of all sixty units: `c_a` detail questions and `c_b` true/false over a five-sentence reading. A2.2 u10 *A Lesson in Five Sentences* is the explicit lesson |
| | | Command of Evidence · textual | B1.2 u04 *Notes Into One Sentence*; B1.2 u09; the Brief Lab in all sixty units, which requires a diagnosis to cite the phrase it rests on |
| | | Command of Evidence · quantitative | **The Decision Room in all sixty units.** Every one presents a data table with six rows of two columns and requires a finding, a comparison, an inference and a decision drawn from it. Book 5 is ten units of nothing else |

The paper's reading passages are drawn from literature, history and social
studies, humanities and science. Book 2 is one unit per subject register; Book 5
is science and social-science data throughout.

## 2 · The four-skill proficiency test, 2026 design

| Section | Task type (2026) | Where the course builds it |
|---|---|---|
| **Reading** | Complete the Words | Part 4's `v_a` gap exercises in all sixty units: eight items per unit, the term completed from its gloss in context |
| | Read in Daily Life | A2.1 throughout: a timetable, an instruction, a homework list, a form, a borrowing record, an absence note. A2.2 u08 *Reading a Table Without Guessing* |
| | Read an Academic Passage | The `read` and `ext` readings in all sixty units; Books 4 and 5 entirely |
| **Listening** | Listen and Choose a Response | **Part 10, the series signature, in all sixty units**: a three-turn ladder in which the student must choose what to say back. Also the `c_e` classify task, which sorts utterances by function |
| | Listen to a Conversation | **The two dialogues in all sixty units**, twelve to thirteen turns each, between a student and a teacher, librarian, adviser or classmate. These are the school analogue of the test's campus conversations: a timetable clash, a lost book, a late form, a mark queried, a reference asked for |
| | Listen to an Announcement | A2.1 u01, u07, u08; A2.2 u06; B2.2 u08 — notices, deadlines and what a public instruction leaves out |
| | Listen to an Academic Talk | A2.1 u05 *Writing Down What Was Said*; A2.2 u02, u07; Book 5's lesson material |
| **Writing** | Build a Sentence | Part 5's `g_a` nine-item gap exercises and `g_b` six contrast pairs in all sixty units: the grammatical choice made in a short exchange |
| | Write an Email | A2.1 u03, u08; B2.2 u03 *An Email With One Question In It*; B2.2 u04 *Asking Somebody to Recommend You*; B2.2 u09 *Saying No, and Saying Not Yet* |
| | Write for an Academic Discussion | **B1.1 u04 *Answering What Was Actually Said* is the explicit lesson**; built throughout Book 3 — a position somebody could disagree with, a reason that can be tested, the other side built first, a hedge sized to the evidence, and a reply of about a hundred words that answers what a classmate actually wrote |
| **Speaking** | Listen and Repeat | Part 7's paired speaking tasks in all sixty units, where one partner reads a line and the other reproduces and transforms it |
| | Take an Interview | **B2.2 u07 *Being Asked Why, Out Loud* is the explicit lesson**; B1.1 u10 *Two Minutes, Standing Up*; the third speaking task in every unit, which is a prompted personal answer of about forty-five seconds |

Scoring on that test is now a 1–6 CEFR-aligned band scale. The course's own
levels are CEFR levels, so a student can be placed directly: Books 1–2 sit at
A2, Books 3–4 at B1, Books 5–6 at B2.

## 3 · What the course deliberately does not do

- It names no test. A student may use the whole course without ever learning
  that either assessment exists.
- It teaches no technique that only works on a test: no elimination strategy,
  no timing drill, no template answer, no predicted-topic list.
- It does not reward length. Every writing model in the course has a stated word
  ceiling, because both assessments now reward precision over volume.
- It does not teach the old integrated speaking and writing tasks, which the
  2026 redesign removed.
