# English for NGOs — the sixty-row alignment

Every unit is one AI capability, one grammar point and the precision faults its
Brief Lab diagnoses. The three are chosen so that each explains the others.

## Fault ladder — labs in which each fault is diagnosed

| Fault | Labs | Repaired with |
|---|---|---|
| unscoped set | 27 | defining relative clauses and articles |
| unbounded quantity | 17 | quantifiers and stated measures |
| unstated criterion | 17 | comparatives and superlatives with a stated basis |
| undefined done | 25 | modality of requirement: shall, is to, must |
| ambiguous referent | 25 | reference, substitution and cohesion |
| missing condition | 25 | conditionals; unless, provided that, failing that |
| unstated exception | 22 | concession: although, notwithstanding, except where |
| hidden assumption | 22 | articles and attribution for given and new information |
