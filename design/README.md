Deliverables for the rebuilt medical-professions courses. Nothing in this
folder is a coursebook; it is the architecture every coursebook will be built
against.

## The four corrections this architecture exists to make

1. **Vocabulary is lexis with definitions**, split into a small productive core
   and a receptive set — not coined phrases with aphoristic glosses, and not
   twenty items a unit tested productively.
2. **Level is conceptual, not just syntactic.** A concept-load gate sits beside
   the sentence-length gate, and governance topics are barred from A2.
3. **Nothing is read or heard before it is previewed.** The preview stage is
   structural and gated.
4. **Every task is scaffolded**: rubric, worked example, model, checklist.

## Still open, for the pilot to answer

- whether 3×3×3×3 fits a real class, or needs a declared core route
- whether the student A2.2 reading band (450–650 words ×3) is too heavy
- whether the productive core should be 8–10 or 6–8 at A2
