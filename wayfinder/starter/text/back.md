# Grammar reference

### Starting Point · Imperatives

| | |
|---|---|
| **Listen.** · **Look.** · **Open your book.** | one word for the verb, no *you* |
| **Don't** worry. | negative: *don't* + verb |

### Unit 1 · Nouns, pronouns and *be*

| | | |
|---|---|---|
| I | **am** | a student. |
| You / We / They | **are** | in Group 2. |
| He / She / It | **is** | in Room 4. |

Short forms: *I'm · you're · he's · she's · it's · we're · they're*.
Short answers keep the full form: *Yes, I **am**.* — never *Yes, I'm*.

| one | more than one |
|---|---|
| **a** pen, **a** book | two pen**s**, three book**s** |
| **an** email, **an** address | four email**s**, two address**es** |

Use **an** before *a, e, i, o, u*. Add **-es** after *s, sh, ch, x*.

### Unit 2 · *be* + adjective, negative *be*, *from* and *in*

| | | |
|---|---|---|
| I | **am** / **'m not** | tired. |
| He / She / It | **is** / **isn't** | free. |
| You / We / They | **are** / **aren't** | late. |

*she is not* → *she **isn't*** or *she**'s not***. But *I am not* → *I**'m not*** only.
**from** = your country or city before. **in** = where you are now.

### Unit 3 · Telling the time; *at*, *in*, *on*

| | |
|---|---|
| **It's** nine **o'clock**. | 9:00 |
| **It's half past** nine. | 9:30 |
| **It's a quarter past** nine. | 9:15 |
| **It's a quarter to** ten. | 9:45 |
| **It's** ten **to** ten. | 9:50 |

Use **past** for the first half hour, **to** for the second. After half past, say the **next** hour.

| **at** + clock time | **in** + part of day | **on** + day |
|---|---|---|
| at six o'clock | in the morning | on Monday |
| **at night** | in the evening | on Friday night |

### Unit 4 · *in*, *on*, *at* with dates; question words

| **in** + month, year | **on** + day, date | **at** + clock time |
|---|---|---|
| in April, in 2026 | on Friday, on 4 April | at nine o'clock |

Big goes with **in**, small goes with **at**.
**When?** takes a day or a month. **What time?** always takes a clock time.

### Unit 5 · *How much*; demonstratives; plurals

| | one | more than one |
|---|---|---|
| **here** | **this** apple | **these** apples |
| **there** | **that** box | **those** tomatoes |

**How much is** + one thing. **How much are** + more than one.

| add **-s** | add **-es** after s, sh, ch, x | change the word |
|---|---|---|
| apple → apples | box → boxes | person → people |
| note → notes | watch → watches | child → children, man → men |

Consonant + *y* → *ies*: *city → cities*. Vowel + *y* → just *s*: *day → days*.

### Unit 6 · Possessive adjectives; the simple present

| | | |
|---|---|---|
| I → **my** | we → **our** | *My* brother lives here. |
| you → **your** | they → **their** | *Your* form is here. |
| he → **his** · she → **her** · it → **its** | | *Her* name is Priya. |

| | | |
|---|---|---|
| I / you / we / they | **live** | in Portmere. |
| he / she / it | **lives** | in Tabriz. |

### Unit 7 · Negatives and questions; quantity

| | | |
|---|---|---|
| I / you / we / they | **don't** | eat fish. |
| he / she / it | **doesn't** | eat fish. |
| **Do** you …? | Yes, I **do**. / No, I **don't**. | |
| **Does** she …? | Yes, she **does**. / No, she **doesn't**. | |

After *doesn't*, the verb has **no -s**.

| | I count them | I do not count them |
|---|---|---|
| **+** | some / a lot of / a few eggs | some / a lot of / a little rice |
| **−** | not **any** eggs | not **any** rice |
| **?** | **How many** eggs? | **How much** rice? |

### Unit 8 · *have* and *has*; frequency

| | | |
|---|---|---|
| I / you / we / they | **have** / **don't have** | a headache. |
| he / she / it | **has** / **doesn't have** | a temperature. |
| **Does** she **have** …? | never *Does she has…?* | |

*once* a day · *twice* a day · *three times* a day · *every* four hours · *after* food · *before* bed

### Unit 9 · Present continuous; adjective + noun

| | | |
|---|---|---|
| I | **am wearing** | a coat. |
| He / She / It | **is raining** | now. |
| You / We / They | **are standing** | by the door. |

Present continuous = **now**. Simple present = **always**.
The adjective comes **before** the noun and never takes **-s**: *two big coats*.
Weather starts with ***It's***: *It's cold. It's raining.*

### Unit 10 · Possessive *'s*; prepositions of place

| | |
|---|---|
| one person | Mei**'s** window |
| a name ending in s | Mr Rivas**'s** key |
| more than one | the student**s'** kitchen |
| a thing, not a person | the door **of** the kitchen |

***it's*** = *it is*. The possessive is ***its***, with no apostrophe.

**in** the kitchen · **on** the table · **under** the bed · **above** the sink · **next to** the door
· **between** the bed and the desk · **behind** the door · **in front of** the window

### Unit 11 · *What* and *Where*; directions

| | | |
|---|---|---|
| **What** | are you **doing**? | I'm printing. |
| **Where** | are you **going**? | To the post office. |
| **Where** | **is** the printer? | Next to the computers. |

Question word, then *am / is / are*, then the person, then *-ing*.
**Go straight on · Turn left · Turn right · past · opposite · between · on the corner**

### Unit 12 · *can* and *can't*

| | | |
|---|---|---|
| I / you / he / she / we / they | **can** | lift it. |
| I / you / he / she / we / they | **can't** | drive. |
| **Can** you **drive**? | Yes, I **can**. / No, I **can't**. | |

*Can* never takes **-s** and the verb after it is plain: *she can drive* — never *she can drives*
or *she can to drive*.

# Audio index and scripts

There are **195 tracks** in Wayfinder Starter: 3 in Starting Point and 16 in each of the twelve
units. The pattern is the same every unit, so a track number tells you what kind of track it is.

| Track | Lesson | What it is |
|---|---|---|
| **01** | Lesson 1 | Gist listening — the opening scene, with one question |
| **02** | Lesson 1 | Listen and repeat — vocabulary set A |
| **03** | Lesson 1 | Listen and check — vocabulary set B |
| **04** | Lesson 2 | The reading text, read aloud |
| **05** | Lesson 3 | The grammar conversation |
| **06** | Lesson 3 | Listen and repeat — the second structure |
| **07** | Lesson 4 | Focused listening — complete the board, notice or list |
| **08** | Lesson 4 | Pronunciation model |
| **09** | Lesson 4 | Pronunciation — circle the word you hear |
| **10** | Lesson 4 | The model conversation |
| **11** | Lesson 4 | Listen and repeat — the question chart |
| **12** | Lesson 4 | On the Job — three short workplace exchanges |
| **13** | Lesson 5 | The picture story |
| **14** | Lesson 5 | The model text, read by its writer |
| **15** | Lesson 5 | The second speaker |
| **16** | Review | Think It Through — the case |

**Most tracks read text that is printed in the book.** Tracks 02, 03, 04, 05, 06, 10, 11, 12, 14 and
16 are the words on the page, read aloud at about 100 words a minute with a clear pause at every
sentence. They need no separate script.

**Six kinds of track are not printed in the book**, because the learner has to catch something that
is not in front of them. Those scripts are below.
