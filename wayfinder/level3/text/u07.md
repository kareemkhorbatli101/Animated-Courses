> *Tidewell Bank · customer information · section 9*
>
> 1  **9.1 What we will never do.** We will never telephone you and ask you to read out a
> 2  security code, move money to a "safe account", or install software so that we can help you.
> 3  No genuine member of our staff will ever ask for any of these, in any circumstances.
>
> 4  **9.2 Reporting.** Tell us as soon as you become aware of a payment you did not authorize.

**1B  Underline the two conditional sentences. Which one is about a real possibility now?**

**1C  Study the chart.**

| Type | Form | Example |
|---|---|---|
| **Always true** | if + present, present | If you report it, they **investigate**. |
| **Likely future** | if + present, will | If you call them, they'**ll** tell you. |
| **Instruction** | if + present, imperative | If you get a message, **open the app**. |
| **Negative** | unless = if … not | **Unless** you report it, nothing happens. |

> **Grammar Note** — The *if* half never takes *will*. "If it will rain" is wrong in English
> however reasonable it sounds; the future lives in the other half of the sentence. This is true
> in almost no other language the learners in this book speak, which is why it takes three years
> to stop.

### 2 · Future time clauses

**2A  Study the chart.**

| Word | Example |
|---|---|
| **when** | I'll call you **when I get** the reference number. |
| **before** | Check the address **before you click** anything. |
| **after** | **After they refund it**, they will investigate. |
| **until** | Don't spend it **until the investigation finishes**. |
| **as soon as** | Report it **as soon as you notice**. |

> **Grammar Note** — Same rule as the conditional, and for the same reason: after *when*,
> *before*, *after*, *until* and *as soon as*, English uses the present for a future event. *When
> I will get it* is wrong; *when I get it* is right, and it still means tomorrow.

### 🌐 CULTURE CHECK

Refusing to answer an official-sounding question is easy for some people and almost impossible

Fraud works on that, deliberately.
