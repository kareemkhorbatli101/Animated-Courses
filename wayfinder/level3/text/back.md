# Grammar reference

Every structure in this book, in unit order, with the rule stated once and the error it causes
stated beside it. The second column is the one worth reading twice.

## Starting Point · Parts of speech and word families

| | |
|---|---|
| **Noun** names · **verb** acts · **adjective** describes a noun · **adverb** describes a verb or adjective | *very agree* — *agree* is a verb, and *very* can only modify an adjective or an adverb |
| **Word families**: decide → decision → decisive → decisively | Learning one member and guessing the others produces *decidement*, *decisionly*, *advisement* |
| **Subject–verb agreement**: *everybody* is singular | *Everybody were* — common, understood, and wrong |

## Unit 1 · Present and past review; yes/no questions; adjectives and adverbs

| | |
|---|---|
| **Present simple**: she studies · she doesn't study · does she study? | Third person *-s* disappears first under pressure |
| **Past simple**: she studied · she didn't study · did she study? | *Did she studied* — after *did*, the verb returns to its base form |
| **Yes/no questions** take an auxiliary: do, did, be, have, can | A yes/no question is harder to avoid than *what about …?* |
| **Adjective vs adverb**: a simple form · she filled it in simply | *She speaks English very good* |
| **Irregular adverbs**: good → well, fast → fast, hard → hard | *Hardly* is not the adverb of *hard*: *he hardly worked* means almost nothing was done |

## Unit 2 · *be going to* / *will*; *would rather*; *very* / *too*

| | |
|---|---|
| **be going to** — a plan already made, or a prediction with visible evidence | *I will book it yesterday* |
| **will** — a decision made now, a promise, an opinion about the future | Both forms predict; *going to* points at the evidence, *will* points at the speaker |
| **would rather** + base verb · would rather X than Y · I'd rather not | *I'd rather to stay* — no *to* |
| **very** describes · **too** complains · **too … to** gives the consequence | *The hall is too nice* — *too* needs a problem |

## Unit 3 · *as … as*; comparatives; superlatives

| | |
|---|---|
| **as + adjective + as** — the same · **not as … as** — less | *It isn't so fast as* — use *as … as* |
| **Comparative**: faster · easier · more useful · better, worse | *more quicker* |
| **Superlative**: the fastest · the easiest · the most useful · the best | *the most bad* — the irregular is *the worst* |
| **Degree**: much / far / slightly / almost as … as / by far the | *very better* — *very* cannot modify a comparative |

## Unit 4 · Present perfect; *for* / *since*; contractions

| | |
|---|---|
| **have/has + past participle** — started in the past, still true now | *I have applied last week* — a finished time forces the past simple |
| **for** + a length of time · **since** + a point in time | *for 2021* |
| **Experience**, time not stated: *I've managed a team* | *How long …?* works with both *for* and *since* |
| **Contractions**: *he's* = he is **and** he has | *He's worked* is *has*; *he's working* is *is*. Only the next word decides |

## Unit 5 · Present perfect questions; *ever* / *already* / *yet*

| | |
|---|---|
| **Have + subject + participle?** · short answer: Yes, I have | *Have you ever been done it* — one participle only |
| **ever** and **never** go before the participle | *Have you ever done it?* asks about a whole life |
| **already** before the participle · **yet** at the end | *Not already* — the negative is *not yet* |
| **Present perfect vs past simple** | Unfinished period → perfect; finished period → simple. *This morning* changes at midday |

## Unit 6 · Phrasal verbs; possessive pronouns

| | |
|---|---|
| **Separable**: put the crate down / put down the crate | With a pronoun it **must** separate: *put it down*, never *put down it* |
| **Inseparable**: run out of · look after · put up with | The object always follows the whole verb |
| **Possessive pronouns**: mine, yours, his, hers, ours, theirs | No apostrophe in *hers*, *ours*, *yours*, *theirs* |
| **its / it's** | *its* is possessive; *it's* is always *it is* or *it has* |

## Unit 7 · Real conditionals; future time clauses

| | |
|---|---|
| **If + present, will** — a likely future | *If it will rain* — the *if* half never takes *will* |
| **If + present, present** — always true · **if + present, imperative** — instruction | *Unless* = *if … not*; *unless you don't* is a double negative |
| **when / before / after / until / as soon as + present** for a future event | *when I will know* |
| The **order of clauses** is not the order of events | *Before I pay, I want it explained* — the explaining comes first |

## Unit 8 · *used to*; present perfect continuous

| | |
|---|---|
| **used to + base** — true before, not now | *Used to* always means **not now** |
| **didn't use to** · **did you use to?** | No *d*: *did* already carries the past |
| **have/has been + -ing** — started in the past, still going | *I am walking since June* |
| **Simple or continuous** | Counted and finished → simple: *I've walked 300 km*, not *been walking* |

## Unit 9 · Time clauses; *and … too*, *and … not either*, *but*

| | |
|---|---|
| **before / after / when / as soon as / until** | Present form for a future event, as in Unit 7 |
| **too** with positives · **either** with negatives | *and he didn't too* |
| **and so + auxiliary** · **and neither + auxiliary** | *and neither didn't she* — *neither* is already negative |
| **but** for contrast | Joins two clauses that pull against each other |

## Unit 10 · Gerunds as subjects; gerunds and infinitives

| | |
|---|---|
| **Gerund as subject**, always singular | *Writing things down **is** useful* |
| **Gerund after a preposition** | *without saying*, *before leaving*, *interested in working* |
| **Verb + gerund**: avoid, enjoy, finish, suggest, mind, keep, consider | *I avoid to walk* |
| **Verb + infinitive**: decide, agree, refuse, offer, manage, promise | *She agreed giving a statement* |
| **Different meaning**: stop / remember / forget / try + gerund or infinitive | *stopped smoking* ≠ *stopped to smoke* |

## Unit 11 · The passive; *by*; *be able to*

| | |
|---|---|
| **be + past participle**, in any tense | *has been offered*, *will be confirmed*, *may be granted* |
| **by** only when the agent matters | *The window was broken* needs no agent; *decided by the panel* does |
| **be able to** fills the gaps *can* cannot | *I have could* is not English; *I have been able to* is |
| Every passive hides a decider | Turn it into a question: *who decides this?* |

## Unit 12 · Verb + infinitive; verb + gerund or infinitive

| | |
|---|---|
| **+ infinitive**: decide, agree, offer, promise, refuse, hope, expect, manage, fail | *I have decided raising it* |
| **+ object + infinitive**: ask, tell, advise, remind, allow | *They advised to write* — the object is missing |
| **+ gerund**: avoid, consider, suggest, deny, risk, keep, put off | *He keeps to promise* |
| **Different meaning**: regret, try | *I regret telling you* — already said; *I regret to tell you* — about to |

# Closing

You began Wayfinder three books ago with a form you could not fill in. You have just finished a
unit about writing a letter that makes an institution move.

The distance between those two things is not vocabulary. It is the discovery that documents are
written by people, that processes have an order, and that the question *who decides this?* has an
answer and you are allowed to ask for it.

Wayfinder 4 goes further into the places where this matters most: reported speech, the past
perfect, unreal conditionals, and the language of saying what should have happened instead of what
did. You are ready for it.
