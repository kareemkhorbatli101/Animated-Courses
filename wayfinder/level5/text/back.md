# Grammar reference

Every structure in this book, in unit order. The second column is the error it causes, which is
the column worth reading twice.

## Starting Point · Hedging and the aspect system

| | |
|---|---|
| **Eight degrees of hedging on one claim** | Four hedges in one sentence is not caution; it is evasion |
| **Tense and aspect reviewed, through the future perfect** | *By March we'll have finished* promises completion; *we'll be finishing* promises activity |
| **Academic word families** | *substantiate / substantive / substantiation* — the noun hides the actor |

## Unit 1 · Narrative tenses; the past perfect continuous

| | |
|---|---|
| **Past perfect continuous**: *I'd been sitting there for an hour* | For a run of activity up to a past point; the continuous makes the listener feel the duration |
| **Past perfect** fixes the order; **past simple** carries the events | *I had worked there a year* is a completed total; *I had been working* is a stretch you were inside |
| ***would* for past habit** | *Every Tuesday I would take the long way* — makes a period, not a moment |
| **Choosing a tense for effect** | Speed, suspension, weight, distance, a stop |

## Unit 2 · Future continuous and future perfect; graded certainty

| | |
|---|---|
| **will be + -ing** vs **will have + -ed** | *In March* promises activity; *by March* promises completion |
| **will have been + -ing** | Duration up to a future point: *by 2030 we'll have been running it for fifteen years* |
| **Future time clauses take a present form** | *Once we **have seen** the figures* — never *once we will have seen* |
| **Grading certainty** | Four speakers saying *will* can mean four different probabilities |

## Unit 3 · Modals of deduction

| | |
|---|---|
| ***must*** = the only explanation I can see | Not obligation; its negative is ***can't***, never *mustn't* |
| ***must have / can't have / might have + -ed*** | *She must not got my message* |
| ***should have + -ed*** = expected and didn't happen | The log should have been signed, and wasn't |
| **The modal reports how many explanations you have thought of** | Which is why a person who has thought of fewer sounds more certain |

## Unit 4 · Mixed conditionals; *wish* and *if only*

| | |
|---|---|
| **Mixed (past → present)**: *If I'd taken it, I wouldn't be here* | *I wouldn't have been here now* mixes the halves the wrong way |
| ***wish* + past** for a present state; **+ past perfect** for regret | *I wish I asked* → *I wish I had asked* |
| ***wish* + *would*** only for other people's habits | *I wish I would* is almost always wrong |
| ***otherwise*** states the alternative outcome | *I turned it down; otherwise I'd be in another city* |

## Unit 5 · The passive across tenses; *have something done*

| | |
|---|---|
| **Nine passive forms**, present simple to infinitive | *The lift has been took out of service* |
| ***have / get + object + -ed*** | *We had serviced the boiler* means you did it; *we had the boiler serviced* means you arranged it |
| ***needs + -ing*** | *The window needs replacing* — not *needs to replacing* |
| **Accurate passive vs evasive passive** | *A decision was taken* — decisions do not happen; they are taken |

## Unit 6 · Relative clauses, defining, non-defining and reduced

| | |
|---|---|
| **Defining: no commas, *that* allowed** | *The strip that runs behind Ferry Lane* — tells you which one |
| **Non-defining: commas, never *that*** | *The strip, which is unnamed, runs …* — adds a fact |
| **Reduced**: drop the pronoun and *be* | *the path worn to bare earth* · *the people using it* |
| **Quantifier + *of whom / of which*** | *forty-six households, most of whom have no garden* |

## Unit 7 · Reporting verbs; backshift

| | |
|---|---|
| **Backshift** when the reporting verb is past | present → past; past → past perfect; *will* → *would* |
| **No backshift** when the claim still stands | *She said the timetable is fixed* — reports it as still standing |
| ***say*** takes no object; ***tell*** requires one | *She said us that …* |
| **Six verb patterns** | *deny + -ing* · *refuse + to* · *assure + object + that* · *object to + -ing* |
| **The verb carries a judgement** | *insisted* implies opposition; *admitted* implies reluctance; only *said* adds nothing |

## Unit 8 · The hypothetical past; concession

| | |
|---|---|
| ***If I were …*** for a position you do not hold | *If I was against this* |
| ***It's time* / *I'd rather* / *I'd sooner*** | Take a past form for present meaning: *it's time we decided* |
| **Five concessive moves** | Concede then counter · concede the fact, deny the conclusion · accept the smaller · reverse the burden · name the trade-off |
| **A real concession states the point at its strongest** | *Of course, some people have concerns* is a dismissal wearing a concession's coat |

## Unit 9 · Participle clauses; nominalization

| | |
|---|---|
| **Present, perfect and past participle clauses** | *Having reviewed it, we cut it* · *Written in 2019, it is out of date* |
| **The subject must be shared with the main clause** | *Having reviewed the leaflet, the text was shortened* — the text reviewed nothing |
| **Negative**: *not + -ing* | *Having not the figures* |
| **Undoing nominalization** | *there is a requirement for consent* → *you must consent* |
| **A noun needs no subject** | Which is why *a decision was taken* and *the decision-making process concluded* both lose the actor |

## Unit 10 · Inversion; cleft sentences

| | |
|---|---|
| ***it*-cleft, *what*-cleft, *all*-cleft, *the reason*-cleft** | Puts the point last, where the voice falls |
| **Inversion after a negative adverbial** | *Never have so few believed it* — one in a speech is striking, three is a performance |
| ***Only when …*** inverts the **second** clause | *Only when they objected did anything change* |
| **English puts new information at the end** | A sentence whose last word is not the point has been built backwards |

## Unit 11 · Articles, determiners, quantifiers

| | |
|---|---|
| ***a*** creates a thing that must be obtained; ***the*** presupposes one already defined | *the cleaning of the carpets* points at a cleaning the document never defines |
| **Zero article** for a class or a state | *Carpets must be left clean* |
| ***any*** gives the other side the choice | *may deduct any reasonable costs* vs *the reasonable costs* |
| ***few / little*** are near-negative; ***a few / a little*** are not | In a clause, that difference is money |
| ***each*** (singly) vs ***every*** (no exceptions) | *All room is listed separately* |

## Unit 12 · Discourse markers; hedging; cohesion

| | |
|---|---|
| ***however*** is an adverb, not a conjunction | *The gap is large, however the categories differ* is a comma splice |
| **Front, mid and end position** | Mid-position lowers the marker and raises the sentence |
| **Six marker functions** | Adding · contrasting · conceding · concluding · exemplifying · reframing |
| **One hedge per claim** | Two is caution; three or more is evasion, and the honest sentence is *I don't know* |
| **A marker is a promise about a relationship** | *Moreover* in front of a paragraph that adds nothing breaks it |

**Three honesty notes, printed here because they are printed in the units too.**

- **Unit 3 is built on a disagreement.** Two summaries of the same IEA report give 43% and "almost
  45%" for the same 2030 projection. The unit prints both, sets the measured 2024 and 2025 figures
  beside them, lists four things that could explain the difference, and says plainly that it does
  not know which. That is the unit's subject, not an embarrassment in it.
- **Units 9 and 11 disagree with each other by a factor of three.** Two academic studies of
  privacy-policy length give 5.6 minutes and 17 minutes for "the average policy". Both are honest.
  The samples, the years and the assumed reading speeds all differ. Unit 11 works through why, and
  then makes the point that the argument survives the lower figure, so the disagreement does not
  need adjudicating.
- **Unit 5's figure is rounded differently by its own publishers.** UN DESA's SDG reporting gives
  1.16 billion; UN-Habitat rounds the same estimate to 1.1 billion. The unit uses 1.16 billion and
  says in the text that the rounding is a house style and not a dispute.

**Everything else in this book is invented.** Portmere is not a real city. The Portmere Civic
Forum, Portmere Adult Learning Service, Portmere Energy Forum, Harwell Lifts, Cranbourne House and
Ferry Lane are not real bodies or places. Every character, letter, notice, minute, clause and
photograph described in these pages was written for this book.

# Closing

Five books ago you learned to fill in a form. Three books ago you learned to ask who had decided
something. In the last book you learned to report what somebody else said without becoming them.

This book has been about one thing, approached twelve times: the difference between what you know
and what you are claiming. You have told a story and put back the part you had trained yourself to
cut. You have said how sure you are, with a number. You have said *I was wrong about the key*. You
have asked what evidence would satisfy an obligation, and asked who signed something, and asked
what a paragraph is doing. You have taken a position in front of people who knew you and named its
weakness yourself. And you have written the sentence that almost nobody writes, which is *I don't
know, and here is what would settle it*.

None of that is a language skill, exactly. All of it is impossible to do in a language you are
afraid of, which is why it took six books to get here.

Portmere stays where it is. Go and argue with somebody.
