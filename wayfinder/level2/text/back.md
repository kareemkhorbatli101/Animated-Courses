# Grammar reference

### Unit 1 · *want to*, *need to*, *like*

| | |
|---|---|
| I **want to** be a nurse. | the aim |
| I **need to** pass the assignment. | the necessity |
| I **like to** study · I **like studying** | both correct |

After *want* and *need*, always **to** + verb. After *like*, either form.
Information questions: question word, then *do / does / did*, then the subject, then the verb.
**this / that / these / those** — near and far, in space and in time.

### Unit 2 · *will*

| | |
|---|---|
| It **will** rain. | prediction |
| I**'ll** help you. | a decision made as you speak |
| I**'m going to** book the hall. | a plan made before |

**at** a point · **on** a day or surface · **in** something or a period.
**by** nine = not later than nine. **until** nine = up to nine, then it changes.

### Unit 3 · Comparatives

| | |
|---|---|
| cheap → cheap**er** · big → big**ger** · easy → eas**ier** | short words |
| expensive → **more** expensive | long words |
| good → **better** · bad → **worse** · far → **further** | irregular |
| A is cheaper **than** B. | always *than* |

**much / far / a lot** cheaper = a big difference. **a bit / slightly** = small.
**Which** for a known set; **what** for an open question.
**Is … allowed?** · **You're not allowed to …** · **… isn't permitted.**

### Unit 4 · Simple past, regular

| | |
|---|---|
| work → work**ed** · train → train**ed** · carry → carr**ied** · stop → sto**pped** | |
| I **didn't** check. | no *-ed* after *didn't* |
| **Did** you check? | no *-ed* after *did* |

Three sounds: /t/ *walked* · /d/ *trained* · /ɪd/ *wanted* (only after *t* and *d*).
Adverbs of manner: careful → careful**ly**, easy → eas**ily**, good → **well**.

### Unit 5 · *might*, *should*, requests

| | |
|---|---|
| It **might** be wrong. | possible |
| You **should** write it down. | advice |
| You **shouldn't** sign it. | advice against |
| **Can / Could you** …? | request, *could* is more careful |
| **Do you mind if I** …? | permission |

### Unit 6 · Two present tenses

| present simple — usually | present continuous — now, this week |
|---|---|
| I **use** eleven gigabytes. | I**'m using** more this month. |
| She **works** at the library. | She**'s working** late all week. |

Never continuous: *know, want, need, like, believe, mean, understand*.
Two objects: *She sent **me** **a message*** or *She sent **a message** **to me***. If both are
pronouns, use the second: *She sent **it to me***.

### Unit 7 · Quantity

| | I count them | I don't count them |
|---|---|---|
| **+** | a few · several · three | a little · some |
| **−** | not any · not many | not any · not much |
| **?** | **How many**? | **How much**? |

**There's** one · **There are** more than one · **There isn't / aren't any**.

### Unit 8 · Irregular past; *have to*

| | | | |
|---|---|---|---|
| be → was/were | go → went | have → had | do → did |
| fall → fell | come → came | see → saw | take → took |
| get → got | give → gave | eat → ate | drink → drank |
| break → broke | hit → hit | put → put | cut → cut |
| feel → felt | lose → lost | leave → left | tell → told |

After *did* and *didn't*, the verb returns to its plain form.
**have to** = necessity from outside. **had to** = the past of it. **don't have to** = not
necessary.

### Unit 9 · Purpose, degree, *would like*

| | |
|---|---|
| I came **to ask**. | purpose |
| I came **because** the app was wrong. | reason |
| It's **too** expensive. | more than acceptable |
| It's **not** cheap **enough**. | less than needed |
| I**'d like** a refund. · I**'d like you to** refund it. | the negotiable request |

*enough* goes **after** an adjective and **before** a noun.

### Unit 10 · *must*

| | |
|---|---|
| You **must** register. | obligation |
| You **must not** work on this visa. | prohibition |
| You **don't have to** pay. | not necessary |
| You **should** register with a doctor. | advice |

*must not* and *don't have to* are opposites. *must* has no past — use **had to**.

### Unit 11 · Past continuous

| | |
|---|---|
| I **was cooking** when the power **went**. | background, then event |
| **While** I **was cooking**, the power **went**. | the same with *while* |
| **There was** a bang. · **There were** four streets. | |

The long thing takes *-ing*; the sudden thing does not.

### Unit 12 · Superlatives

| | comparative | superlative |
|---|---|---|
| short | cheap**er** | **the** cheap**est** |
| long | **more** expensive | **the most** expensive |
| irregular | better · worse · further | **the** best · **the** worst · **the** furthest |

Comparative for two; superlative for three or more. **one of the cheapest** is safest.
