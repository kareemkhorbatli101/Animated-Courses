# Grammar reference

Every structure in this book, in unit order. The second column is the error it causes, which is
the column worth reading twice.

## Starting Point · Register and the tense system

| | |
|---|---|
| **Four registers**: informal, neutral, formal, academic | A formal sentence in a shop is not politer; it is stranger |
| **Formal English removes the person** | Useful for emphasis; evasive when a decision needs an owner |
| **Eight tenses, reviewed** | The past perfect fixes the order of two past events; it is not a more past past |

## Unit 1 · Action and stative verbs; three kinds of question

| | |
|---|---|
| **Stative verbs** take no continuous: know, believe, understand, own, need, prefer, seem | *I am knowing* |
| ***be* + adjective** vs ***being* + adjective** | *She is difficult* (always) vs *she is being difficult* (today) |
| **Yes/no, information and or-questions** | A yes/no question can be dodged; an or-question forces a choice |
| **Senses**: *see, hear, taste* | Stative for perception, active for an arrangement: *I'm seeing the consultant* |

## Unit 2 · The past passive; reflexive pronouns

| | |
|---|---|
| **was / were + past participle** | *The decision was took* |
| **Agent with *by***, only where it matters | *The window was broken* needs no agent; *decided by the panel* does |
| **Passive questions**: *When was it decided? Who was it decided by?* | *Who was it decided from?* |
| **Reflexives** vs ***each other*** | *The two reports contradict themselves* — they contradict *each other* |

## Unit 3 · Reported speech

| | |
|---|---|
| ***say*** takes no person; ***tell*** takes one | *She said me* |
| **Tense shifts back** when the reporting verb is past | present → past; past → past perfect; *will* → *would* |
| **Instructions**: *told us to wait* / *told us not to go* | *told us to not go* |
| **Reported questions** take statement order | *He asked where was I going* |

## Unit 4 · The past perfect

| | |
|---|---|
| **had + past participle**, for the earlier of two past events | Use it once, then return to the past simple |
| **Continuous**: *I'd been doing it since June* | For a run of activity rather than a single act |
| ***'d*** is both *had* and *would* | *I'd done it* reports; *I'd do it* offers |
| **Three past tenses together** | Past perfect fixes the order, past simple carries the story, past continuous sets the scene |

## Unit 5 · Obligation; *should have*

| | |
|---|---|
| ***have to*** — obligation from outside · ***must*** — from the speaker | *must* from a stranger sounds like an order, because it is |
| ***don't have to*** ≠ ***mustn't*** | Opposites, not variants: optional against forbidden |
| ***should have + participle*** | *should of* is not English and appears in reports daily |
| **Passive *should have*** | *The barrier should have been up* names no one and fixes the problem |

## Unit 6 · Adjective clauses

| | |
|---|---|
| **Defining**: no commas, *that* allowed | the colleague **who** produces the figures |
| **Non-defining**: commas, no *that* | Priya, **who** writes the report, stayed |
| ***whose*** + noun | never *who's*, which is *who is* |
| ***which*** for a whole clause | He was late, **which** nobody recorded |

## Unit 7 · The present unreal conditional

| | |
|---|---|
| **If + past, would + base** | the past tense marks it unreal, not past |
| ***were*** for all persons | *If I were you* is never wrong; *if I was* is informal |
| ***could* / *might*** in the main clause | ability and possibility rather than certainty |
| **Never *would* after *if*** | *If we would have more money* |

## Unit 8 · *-ed* / *-ing* adjectives; degree; *so* / *such*

| | |
|---|---|
| ***-ed*** = how a person feels · ***-ing*** = what a thing is like | *I am boring* means something else entirely |
| **absolutely** with extremes, **very** with ordinary adjectives | *absolutely slow* |
| ***so*** + adjective + *that* | *so slow that I rang twice* |
| ***such*** + (a) + adjective + noun + *that* | *such a slow process that I gave up* |

## Unit 9 · *should* / *ought to* / *had better*; gerund or infinitive

| | |
|---|---|
| ***had better*** carries a consequence | It is a warning, not a polite *should* |
| ***had better*** contracts to *'d better* and then to *better* | which is why it is written as a bare imperative and reads as rude |
| ***stop / remember / try / regret / go on*** change meaning | *stopped smoking* ≠ *stopped to smoke* |
| ***regret to tell*** vs ***regret telling*** | about to say it, against wishing you had not |

## Unit 10 · Indirect questions; *if* / *whether*

| | |
|---|---|
| **Statement word order** after every indirect opener | *Could you tell me when does it close* |
| **No second auxiliary** | the giveaway that a direct question has been translated whole |
| ***whether*** after prepositions and before infinitives | *the question of whether*; *whether to respond* |
| ***if*** in speech, ***whether*** always safe | *whether or not* when the alternative is stated |

## Unit 11 · Tag questions

| | |
|---|---|
| **Auxiliary of the main clause, polarity flipped** | *It isn't accurate, is it?* |
| **No auxiliary → *do / does / did*** | *You read it, didn't you?* |
| ***aren't I*** is the one irregular tag | *amn't I* does not exist |
| **Rising = asking · falling = telling** | The difference vanishes in writing, which is why tags in email misfire |

## Unit 12 · Gerunds after prepositions

| | |
|---|---|
| **preposition + gerund** | before leaving · without asking · after reading |
| **adjective + preposition + gerund** | good **at** finishing · interested **in** learning |
| ***to* as a preposition** | committed **to doing**, look forward **to hearing**, object **to being** |
| **The test** | if a noun fits after *to*, the verb takes *-ing* |

# Sources

Every figure quoted in a reading text in this book is real and its source is named in the text.
Three of them carry a caveat, and the caveat is printed in the book rather than kept out of it.

| 2 | Reuters Institute, *Digital News Report 2025* |

| 8 | European Commission, *Consumer Conditions Scoreboard 2025* |
| 9 | WHO / ILO, *Mental health at work* |
| 10 | International IDEA, *Global State of Democracy* |
| 11 | European Commission, *Consumer Conditions Scoreboard 2025* |
| 12 | World Economic Forum, *Future of Jobs Report 2025* |

**The three caveats.**

- **Unit 5** cites a figure whose reference year is 2019 and whose publication year is 2023. It is
  the most recent global estimate that exists. The text says so and the task asks about it.
- **Unit 9** cites work published in 2022 and still current in the WHO's own fact sheet. The text
  says what the figure was built from and what it does not establish.
- **Units 8 and 11** cite a figure whose base is not stated in the published summaries available.
  Rather than drop it or pretend it is clear, the book prints it, says the base is missing, works
  through three possible bases, and asks the learner what they would need to know before quoting
  it. That is the skill those units are for.

**Everything else in this book is invented.** Portmere is not a real city. Northgate Distribution,
Linkwave, Tidewell Bank, Kestrel Logistics, Freshline and Portmere Motor Data are not real
companies. Every character, letter, form, review and transaction in these pages was written for
this book.

# Closing

Four books ago you could not fill in a form. Two books ago you learned to ask who decided
something. In this book you have learned to report what somebody else said without becoming them,
to say what should have happened without accusing anybody, and to ask a question that *fine*
cannot answer.

What remains is the hardest and the simplest: saying something difficult to somebody who does not
want to hear it, in a language that is not your first, and being understood. That is Wayfinder 5,
and if you have got this far you will finish it.
