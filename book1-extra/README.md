# Al-Hasan International — Extra Material for Student Book 1

**CEFR A2 · 120 lessons · ten units · runs from a folder, offline**

Extra reading and listening for every unit of *Al-Hasan International
Student Book 1*. Ten units, twelve lessons each: **six readings and six
listenings**, every one of them read aloud by the speech voices already
installed on the computer the browser is running on. No audio files, no
build step, no network.

Unzip and open `index.html`.

---

## What a lesson is

| Step | | Exercises |
|---|---|---|
| 1 | Before you read / listen | 3 |
| 2 | The text or the conversation — audio + glossary | — |
| 3 | Comprehension | 6 |
| 4 | Words in context | 3 |
| 5 | After you read / listen | 3 |

**15 exercises a lesson, 1,800 in the pack.** Twelve mark themselves
(multiple choice, several-answer, true/false, gap-fill, matching,
ordering); three are written — one short answer and two longer ones —
and show a model answer that the learner compares with their own and
marks.

Scores are kept per lesson and totalled per unit and on the front page.
Everything stays in the learner's own browser.

## The audio

* Readings: sentence by sentence, with the spoken sentence highlighted.
* Conversations: **two voices**, A and B, so the speakers sound like two
  people. Both are chosen in the player; speed runs 0.7–1.15.
* Transcripts start hidden — listen first, reveal when you want.
* If the machine has no voices, the page says so and gives the
  Windows / macOS / Linux steps for installing them.

## Files

```
index.html             the shell; regenerated by build.py
assets/site.css        one stylesheet
assets/app.js          router, eight exercise types, speech, scoring
assets/data/u1r1.js …  one file per lesson, 120 of them
build.py               rewrites index.html from whatever is in data/
check.py               gates every lesson file
README.txt             the same notes, for learners
```

`check.py` enforces: 15 exercises per lesson, the required fields,
`paras:` on readings and `turns:` + `setting:` on listenings, a model
answer on every written task, well-formed multiple-choice / gap /
match / order data, no duplicate ids, and no stray non-Latin characters.

### Adding a lesson

Copy any file in `assets/data/`, change `id`, `unit`, `kind` and `n`,
write the content, then:

```sh
python3 check.py     # must print 0 problems
python3 build.py     # rewrites index.html
```

### Printing

Open a lesson and print the page: the text comes out at the top with the
exercises below it, in order.
