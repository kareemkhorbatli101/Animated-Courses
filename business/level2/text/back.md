# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it causes, which is
the column worth reading twice.

## Starting Point · the four tenses you already have

| | |
|---|---|
| **Present simple** for routine, **present continuous** for now | *I work here* · *I'm covering for Yara* |
| **Past simple** for a finished event with a time | *We sent it on Tuesday* |
| ***going to*** for a plan, ***will*** for a decision made as you speak | |
| **Say the tense you mean** | *we send it* and *we're sending it* are two different promises |

## Unit 1 · Comparatives and superlatives

| | |
|---|---|
| **Short adjective + -er / -est**; long adjective + ***more*** / ***most*** | *more cheap* |
| **Irregular** | good → better → best · bad → worse → worst · far → further |
| **A superlative needs a unit** | *the cheapest* **per what?** |
| **A specification is read by somebody who was not there** | every dimension, every tolerance, in writing |

## Unit 2 · The present perfect for recent events

| | |
|---|---|
| **have / has + past participle** | *We've sent the order* |
| **No finished time with the present perfect** | *I've sent it yesterday* |
| **Confirm what you have done, not what you will do** | one is evidence, the other is hope |
| **An order confirmation repeats the numbers back** | that is the whole point of it |

## Unit 3 · Present perfect against past simple; *yet*, *already*, *still*

| | |
|---|---|
| **Present perfect** = the result now; **past simple** = the event then | |
| ***yet*** in questions and negatives · ***already*** earlier than expected | *I haven't had it yet* |
| ***still*** = it continues and you are not pleased | *They still haven't replied* |
| **Chase the invoice, never the person** | and never on the first day it is late |

## Unit 4 · *must* / *have to* / *should* / *don't have to*

| | |
|---|---|
| ***must*** and ***have to*** = necessary; ***don't have to*** = your choice | |
| ***should*** = advice, not obligation | a contract that says *should* has not promised you anything |
| **No *to* after *must***; no *-s* on *must* | *she musts sign* |
| **Read the clause number aloud when you quote it** | 11.3 is not 13.1 |

## Unit 5 · The passive, present and past

| | |
|---|---|
| **be + past participle** | *The batch was rejected* |
| **Use it when the actor does not matter — or when naming them would be a fight** | |
| ***by*** names the actor if you need them | *signed by the supervisor* |
| **A complaint reply says what will change, not who was at fault** | |

## Unit 6 · Defining relative clauses

| | |
|---|---|
| ***who*** for people · ***which*** / ***that*** for things · ***whose*** for possession | |
| **No second subject** | *the person who he signed it* |
| **No comma on a defining clause** | the comma turns it into extra information |
| **A record is written for the person who will read it alone** | including you, in a year |

## Unit 7 · Sequencers with the passive

| | |
|---|---|
| **first · then · after that · meanwhile · finally** | and a pause after each one, out loud |
| ***Meanwhile*** = at the same time; ***after that*** = next | they are not interchangeable |
| **A step containing *properly*, *correctly* or *as required* is not a step** | replace the word with the number |
| **Say when you do not know the reason** | *the reason is not documented* is an honest line |

## Unit 8 · *as … as*; *the most*; *not as … as*

| | |
|---|---|
| ***as*** + adjective + ***as*** · ***not as … as*** · ***twice as … as*** | *as fast than* |
| **Put the number and the unit inside the comparison** | *eleven percent cheaper per carton* |
| **Concede the strongest point against you, in figures** | a reader who sees that stops hunting |
| **The cheapest unit price and the cheapest order can be different suppliers** | |

## Unit 9 · Question forms; indirect questions

| | |
|---|---|
| **Subject questions take no auxiliary** | *Who signed it?* but *Who did you ask?* |
| **Indirect questions go back to statement order** | *Could you tell me when it ends?* |
| ***if*** or ***whether*** for an indirect yes/no question | *Do you know if we gave notice?* |
| ***Who owns this action?*** | the most useful question in any meeting |

## Unit 10 · The first conditional

| | |
|---|---|
| ***if*** + present simple, ***will*** / ***won't*** | *if they will pay late* |
| ***unless*** = if … not | *unless February is settled* |
| ***when*** is certain, ***if*** is not | and customers hear the difference |
| **Never write *will* about something you are not going to do** | the empty threat teaches them to wait |

## Unit 11 · *must* / *mustn't* / *needn't*; imperatives

| | |
|---|---|
| ***mustn't*** = forbidden · ***needn't*** = not necessary | they are not opposites of each other in the way people expect |
| ***have to*** often signals a rule from outside | *we have to keep it for five years* |
| **Give the reason with the rule** | a rule without one is obeyed only while somebody is watching |
| **A root cause is a thing, not a person** | "carelessness" is where thinking stopped |

## Unit 12 · Past continuous and past simple

| | |
|---|---|
| **was / were + -ing** for the background; **past simple** for the event | |
| ***while*** + continuous · ***when*** + simple | *while we were fixing it, we lost a customer* |
| **State verbs stay simple** | *we were knowing* |
| **Two sources, two numbers: print both and name your choice** | and say when you will check |

## Four ways to count a late payment, and why they are not the same

This book quotes four real measurements of late payment. They sound like the same thing. They are
not, and nothing in the back matter of this book matters more than the next four lines.

| Unit | What it measures | The figure |
|---|---|---|
| 3 | **Total days to be paid**, terms included | 51 days (32 agreed + 19 late) |
| 4 | **Days past the deadline**, after an average 36-day term | 21 days |
| 5 | **The share of invoices affected** at all | 24% (19% late, 5% never) |
| 10 | **Delay beyond terms, by country** | NL 12 · Europe 18 · UK 21 · US 29 |

A single number built out of any two of those is wrong. The clearest trap is the one Unit 10 is
about: because the four country figures measure delay **beyond agreed terms**, and agreed terms
differ from country to country, a market with short terms can look worse while being paid sooner. A
14-day invoice settled on day 26 is "12 days late". A 60-day invoice settled on day 89 is "29 days
late". The second customer took sixty-three days longer and looks better on the chart.

**If you quote one of these at work, quote it with its definition.** Eleven extra words will save
you a meeting.

## Three more honesty notes, printed here because they are printed in the units too

- **Unit 12 is built on a disagreement.** Two 2026 reports give 56 percent and 55.0 percent for
  the same share, and 7.1 percent and 10.0 percent for its annual growth. The shares are
  effectively one statement; the growth rates are not — compounded over five years they differ by
  roughly a fifth of the market. The reports were published months apart, draw on different
  vintages of the same underlying data, and do not define the category identically. The unit prints
  both, plans on the lower one, and says in writing that the planning figure was a choice.
- **Units 7 and 11 use a figure whose reference year is 2019.** The ILO published it in 2023 and it
  is the most recent global estimate available. The units print the reference year beside the
  figure, and Unit 11 points out the part most readers miss: nearly nine work-related deaths in ten
  are from disease, not accidents, so a site with no accidents is not thereby a safe site.
- **Unit 6's payment-period finding is a report of what suppliers say.** The EU Payment Observatory
  figure above 60 days comes from suppliers reporting their own experience, not from audited
  invoice data. That does not make it wrong. It makes it a different kind of evidence from a bank's
  settlement records, and the unit says so.

**Everything else in this book is invented.** Ostberg is not a real city. Lindmark Freight, Arvo
Components, Brightwell Pharma, Corvid Analytics, Juno Textiles, Sable &amp; Finch, Harbour Mutual,
Terrace Hotels, Teval Transport, Salas Transport, Kjeldsen, Ostergaard and Vandermeer are not real
companies. Every character, contract, order, invoice, procedure, agenda, induction and board paper
in these pages was written for this book. Where a document would in reality depend on the law of a
particular country — notice periods, payment terms, safety duties, retention of records — the book
says so and makes finding your own answer the task.

# Closing

You began this book able to make yourself understood. You end it able to read a specification and
find the assumption inside it, place and change an order so that nobody has to guess, chase money
without losing the customer, read a clause and say what you have actually agreed to, answer a
complaint in a way that keeps the account, write a record the next person can use alone, explain a
process to somebody who has never seen it, compare three suppliers with figures instead of
adjectives, get a skipped item back onto a meeting agenda, say what will happen if an invoice is
not paid and mean it, state a safety rule together with its reason, and report a year honestly
including the part you would rather leave out.

Two sentences to take with you. From Unit 7: **the reason for this is not documented** — the most
useful thing you can write when you do not know. And from Unit 12: **I cannot tell you which of
these two figures is right, and I have planned on the lower one.** Both sentences cost you nothing
and buy you the only thing that matters in business English, which is being believed.
