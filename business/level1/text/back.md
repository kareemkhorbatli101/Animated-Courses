# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it causes, which is
the column worth reading twice.

## Starting Point · *be*; numbers and spelling aloud

| | |
|---|---|
| **am / is / are** | English needs the verb: *I engineer* is not a sentence |
| **A job takes *a* or *an*** | *I am an operations coordinator* |
| **13 / 30** | The difference is the stress, not the ending. Say it twice: "fifteen — one five" |
| **Dates** | Write the month in letters and the argument never happens |

## Unit 1 · *be*; possessives

| | |
|---|---|
| **Short answers** | *Are you Anders?* — ***I am.*** Not *Yes, I am Anders* |
| **noun + 's** for people and companies | *Anders's team* · *Lindmark's warehouse* |
| **plural + '** | *the drivers' break room* — more than one driver |
| ***Whose* / *who's*** | *Whose badge is this?* · *Who's calling?* |

## Unit 2 · The present simple

| | |
|---|---|
| **-s on he / she / it only** | and it disappears in questions and negatives |
| ***does she work***, never *does she works* | the commonest error at this level |
| **Negative** | *We don't sell to the public* |
| **Saying what you do not do** | as useful as saying what you do, and it stops disappointment later |

## Unit 3 · *at* / *on* / *in*; adverbs of frequency

| | |
|---|---|
| ***at*** a clock time · ***on*** a day or date · ***in*** a month, year or part of the day | |
| **No preposition** before *today, tomorrow, next week, every day* | *on tomorrow* is wrong |
| **Frequency adverbs** go before the main verb, after *be* | *She is never late* |
| ***never*** is already negative | *I don't never work Sundays* says the opposite |

## Unit 4 · Imperatives; *can* and *could*

| | |
|---|---|
| **Imperatives** are fine on signs and in systems | to a person they are often too direct |
| **No *to* after *can*, *could*, *would you mind*** | *could you to repeat* |
| ***would you mind* + -ing** | and "No, not at all" means **yes, I will** |
| **Read every number back** | one wrong digit cost nineteen days in Unit 4 |

## Unit 5 · *there is* / *there are*; prepositions of place

| | |
|---|---|
| ***there is / are*** says something exists; ***it is / they are*** says something about it | |
| ***in*** inside · ***on*** a surface · ***at*** a point | *at the door*, *at the loading bay* |
| **Locations run big to small** | aisle, bay, level — so the listener can start walking |
| **Say what is *not* there** | *There's nothing in bay twelve* is a finding |

## Unit 6 · *how much* / *how many*

| | |
|---|---|
| **Countable → *how many*; uncountable → *how much*** | *how much pallets* |
| **Uncountable nouns need a unit** | not *four steels* but *four tonnes of steel* |
| **Some nouns are both** | *two coffees* (cups) · *how much coffee* (the substance) |
| **Write the number in digits and words** | 1,200 (one thousand two hundred) pieces |

## Unit 7 · Present continuous against present simple

| | |
|---|---|
| **Continuous** for now and around now; **simple** for always and usually | |
| **Spelling** | add *-ing* · drop the *e* · double the last letter |
| **State verbs are not continuous** | *know, need, want, mean, understand, cost, have* (= own) |
| **A status needs a time** | "I'll know by ten" is the half of the update people leave out |

## Unit 8 · The past simple

| | |
|---|---|
| **Plain verb after *did* and *didn't*** | *did you found it* is the error that lasts longest |
| **Regular *-ed*, irregular by heart** | find → found · send → sent · read → read ("red") |
| ***ago*** goes after the period | *three days ago*, never *ago three days* |
| **No names in the first paragraph** | a report people can read aloud is a report that gets acted on |

## Unit 9 · *be going to*

| | |
|---|---|
| ***going to*** for a plan you already have, or something you can see coming | |
| ***will*** for a decision made as you speak, an offer or a promise | |
| **Present continuous** for a fixed arrangement | *She's landing at 14:10* |
| ***in*** twenty minutes = after · ***by*** ten = at ten or before | this is how people miss each other at airports |

## Unit 10 · Requests

| | |
|---|---|
| **can → could → would you mind → I was wondering if** | four levels, same request |
| ***would you mind* + -ing** | *would you mind to cover* |
| **Say no in three parts** | answer, one reason, an alternative |
| **One *sorry* is enough** | a long apology makes the other person look after you |

## Unit 11 · Past simple with *because*; apologizing

| | |
|---|---|
| ***because* + clause · *due to* / *because of* + noun** | *because of the ship was rerouted* |
| ***should have* + past participle** | *I should have told you on the tenth* |
| ***I'm sorry for* + noun or *-ing*** | *I'm sorry for tell you* |
| **Bad news goes in the first line** | everything else is layout |

## Unit 12 · *will* against *going to*

| | |
|---|---|
| ***will*** has no *-s* | *she wills send* |
| **Promise, offer, decision now → *will*** | *You'll have it before five* |
| **An action needs one owner and one date** | two owners is the same as none |
| **End with what happens if nobody replies** | that sentence turns an email into a decision |

**Three honesty notes, printed here because they are printed in the units too.**

- **Unit 12 is built on a disagreement, and says so.** 2.1 billion out of 3.6 billion is about 58
  percent, and the summary of the same release says 51.1 percent. The two count different things
  — a count of workers against a share of employment — over slightly different years. At A2 the
  unit does not try to settle it. It teaches the sentence *these are not the same measurement*,
  and asks which figure the learner would put in an email.
- **Unit 5's container figure is from 2023.** It is the most recent year published in the series
  UNCTAD points readers to. The text gives the year, and the task asks what you should write in an
  email when a figure is three years old.
- **Unit 6's forecast has moved twice.** The WTO published 0.5 percent for 2026 in October 2025,
  1.9 percent in March 2026 and 3.9 percent in October 2026. The unit prints the current figure
  with its date, and the *Think It Through* case is about a buyer who planned on an older one.

**Everything else in this book is invented.** Ostberg is not a real city. Lindmark Freight, Arvo
Components, Brightwell Pharma, Corvid Analytics, Juno Textiles, Sable & Finch, Harbour Mutual and
Terrace Hotels are not real companies. Every character, letter, order, invoice, rota, report and
phone call in these pages was written for this book.

# Closing

You began this book able to say your name. You end it able to say your name, spell it, give your
job, explain your company in four sentences, read a rota, check an order, take a message somebody
else can act on, report what went wrong without blaming anybody, look after a visitor, ask for
something, refuse something, and end a meeting with three actions that each have one owner and
one date.

None of that is advanced English. All of it is the English that most work actually runs on, and
very little of it is taught anywhere.

One sentence to take with you, from Unit 4: **sorry, could you say that again?** It is not a
failure. It is the most professional thing in this book, and everybody who is good at working in
a second language says it several times a day.

Ostberg will still be here in Clearline 1.
