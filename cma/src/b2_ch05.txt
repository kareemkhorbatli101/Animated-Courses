WHAT YOU ALREADY KNOW   What you already know
Chapter 6 in this book, the job costing pilot, already used normal costing: actual direct costs plus overhead applied at a predetermined rate. This chapter explains why, and compares it with the other two techniques.
5.1  Three measurement techniques
A product cost has three parts: direct materials, direct labor and overhead. The three techniques differ in how they measure each part. Actual costing uses actual amounts for all three. Normal costing uses actual direct costs but applies overhead with a predetermined rate. Standard costing uses standard quantities and prices for everything.
Each technique suits a different need. Actual costing is exact but late; normal costing is timely; standard costing also sets targets that managers can compare with results. Figure F205-02 compares them.

5.2  Actual costing
Under actual costing, overhead is assigned only when the period ends and the actual overhead is known. In May Beverages spent $222,600 on overhead, so the full cost was $903,000, or $12.90 a case.
Actual costing has two limits. The cost arrives too late for pricing and control during the month. And unit cost jumps with volume, because fixed overhead is spread over whatever the month produces. Figure F205-03 shows fixed overhead per case rising from $2.17 in May to $3.00 in a quiet July.
Figure F205-03. Fixed overhead per case in a busy and a quiet month under actual and normal costing.
Actual costing suits small firms with stable volume, and it is the basis for checking results after the period.

5.3  Normal costing
Normal costing keeps actual direct materials and direct labor, but applies overhead with a predetermined overhead rate: budgeted overhead divided by the budgeted allocation base, set before the year starts. Beverages uses $150 per machine hour.
Applied overhead equals the actual base times the rate. In May the line ran 1,414 machine hours, so applied overhead was $212,100. Figure F205-04 shows the flow: actual overhead collects separately, and the difference is closed at year-end (Chapter 8).
Figure F205-04. Normal costing: actual direct costs plus overhead applied at a predetermined rate.
Normal costing gives a cost as soon as the work is done, and the rate smooths out seasonal swings in fixed overhead. Its limit is that the rate is only an estimate, so applied and actual overhead differ.
FALSE-FRIEND ALERT   Normal costing is not normal capacity
Normal costing means 'actual direct costs plus applied overhead'. Normal capacity (Chapter 8) is a denominator level used to set a fixed overhead rate. French 'coût normal' and Arabic التكاليف العادية can refer to either; check the context.

5.4  Standard costing
Standard costing values every input at what it should cost for the output achieved. Each part equals the standard quantity allowed for the actual output times the standard price. The Beverages standard cost card gives $12.60 a case (Chapter 18 shows how it is built).
The difference between actual cost and standard cost is recorded as variances. Managers study them to control costs, and Book 3 analyzes them in detail. Standard costing suits repetitive production such as bottling.

EXAM TRAP   Standard hours allowed, not actual hours
In standard costing, overhead is applied on the standard hours allowed for the actual output. Using actual hours turns standard costing back into normal costing.
● IFRS CONTRAST   Standards in the financial statements
Both ASC 330 and IAS 2 accept standard costs for inventory only if they approximate actual cost. Standards must be reviewed and updated regularly.

5.5  Variable overhead: components, base and rate
Variable overhead is indirect production cost that changes with activity. On the bottling line it has four components: power for the machines, cleaning chemicals, maintenance supplies, and water and steam. Supervision, insurance and depreciation are fixed overhead.
The allocation base for variable overhead should be what drives it. The bottling line is automated, so power and supplies follow machine hours, not labor hours. On a manual line, such as halva finishing, labor hours may be the better base.
Variable overhead per unit = rate per base unit × base units per product. Figure F205-06 shows that Beverages' components add up to $50 per machine hour. Each case needs 0.02 machine hours, so variable overhead is $1.00 a case.

Keep variable and fixed overhead apart when you need a variable cost. The full predetermined rate of $150 per machine hour mixes both: it gives $1.00 of variable and $2.00 of fixed overhead per case. A special order that uses spare capacity adds only the variable part (Chapter 9).
Test the base before you use it. Plot monthly variable overhead against each possible base, as in Chapter 3, and keep the one with a clear causal link and the better fit. For the bottling line, machine hours pass both tests.
The per-unit figure travels far. It goes on the standard cost card (Chapter 18), into the contribution margin (Chapter 9) and into the flexible overhead budget in Book 3.

Chapter summary
Figure F205-12 brings the chapter together.
Figure F205-12. Chapter 5 summary map: the key rule for each section.
Actual costing uses actual materials, labor and overhead; it is exact but late, and its unit cost moves with volume. Normal costing applies overhead at a predetermined rate times the actual base, which gives timely, smooth costs. Standard costing values the standard quantities allowed at standard prices and records the differences as variances. Variable overhead is the sum of its components; choose a base that drives them, and multiply the rate by the base per unit.
