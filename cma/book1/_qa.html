Quality gate

The source book passes a 33-check gate per chapter. This page holds the site to something comparable, and does it mechanically: it loads every page's real exercise definitions, renders every one of them, and checks the result. Open it after any edit.

Three further checks run when the package is built, because a page opened from file:// cannot read its own neighbours: that every internal link resolves to a file that exists, that no src or href anywhere points at http:// or https://, and that no file uses fetch() or <script type="module"> — all three of which break silently when there is no web server.
