OFFLINE BY DESIGN

No internet, no web server, no install

Open index.html straight from the folder and everything works: every exercise, every figure, every drag-and-drop, and the progress that is saved in this browser on this computer. Pronunciation uses the voices already installed on your computer — on Windows, Chrome and Microsoft Edge expose them directly. If the Arabic icon is dimmed, no Arabic voice is installed; the foot of any chapter page says how to add one.

All eighteen chapters are built: 1,078 exercises over 203 pages, every one of them generated from the author's own chapter and checked against it word by word. Each chapter keeps its own saved progress, so resetting one leaves the others alone.
