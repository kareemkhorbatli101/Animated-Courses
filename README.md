# Animated Courses

Animated English-language course videos, played in the browser.

`index.html` is one complete lesson — "Barada Auto Service, Garage Tour" — in a single self-contained
file. Open the site and press **Play**.

This is the first deployment, published to prove the hosting path end to end. The course catalogue
(several courses, each with its own videos, and independent choices of catalogue language, spoken
language, and one or two subtitle tracks) is designed but not yet built.

---

Built with the AnimatedMatrix XML→video engine. Every video is rendered from a declarative XML
specification; the same specification plays in the browser and renders to MP4, and the two are held to
byte-identical agreement by an automated gate suite.
