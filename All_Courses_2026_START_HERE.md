# Everything built in this project

Five courses, **58 books, 18,448 pages**, plus every chapter split out as a
separate file and every plan and verification report. 399 files in all.

Each course sits in its own numbered folder. Page counts below are real:
each file was rendered to PDF and its pages counted.

## What is not here

**No audio.** Every listening task in the IELTS and TOEFL courses has a
full script with named speakers, printed at the back of the student book
and beside the task in the Teacher's Edition, but there are no sound
files. Read the scripts aloud or have a colleague do it. The recording
spec — speaker count, accent spread, words per minute, pause placement —
is in the IELTS series rebuild plan.

**No photographs.** Every figure in these books is drawn, because we have
no licensed image library. The visual-system document says so plainly and
argues that drawn figures teach better anyway, since a diagram can carry
an argument that a photograph cannot.

**Superseded bundles left out.** Nine earlier `.zip` bundles from along
the way are not included; everything in them is here as loose files, so
shipping them would have doubled the download for nothing.
