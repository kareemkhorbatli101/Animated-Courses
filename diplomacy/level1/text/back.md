# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it causes, which is
the column worth reading twice.

## Starting Point · Four habits

| | |
|---|---|
| **Say it so the other person can write it** | a name at speaking speed is a name nobody records |
| **Write who asked, what, and when** | three facts, in that order, every time |
| ***I don't know, and I'll find out by*** | the second half is what makes the first half professional |
| **Never guess a rule out loud** | a guessed rule is quoted back to you as the ministry's position |

## Unit 1 · *be*; *there is* / *there are*

| | |
|---|---|
| **am / is / are** | English needs the verb: *I third secretary* is not a sentence |
| ***there is*** + singular · ***there are*** + plural | *there is two offices* |
| ***there is / are*** says something exists; ***it is / they are*** says something about it | |
| **A floor, a room number, a department** | three facts and nobody walks the building twice |

## Unit 2 · The present simple; adverbs of frequency

| | |
|---|---|
| **-s on he / she / it only** | and it disappears in questions and negatives |
| ***does she work***, never *does she works* | the commonest error at this level |
| **Frequency adverbs** go before the main verb, after *be* | *She is always here by eight* |
| **Say what you do not do** | it saves a week of somebody waiting |

## Unit 3 · *can* and *could*; *have to*

| | |
|---|---|
| **No *to* after *can* and *could*** | *could you to check* |
| ***can*** = possible or permitted · ***could*** = the polite request | |
| ***have to*** = the rule requires it; ***don't have to*** = it is not required | not *you mustn't*, which forbids |
| **Say which rule, and whose** | the ten-year limit is national law, not an international standard |

## Unit 4 · Imperatives; question forms

| | |
|---|---|
| **Imperatives** are right on a form and often too direct to a person | *Sign here* → *Could you sign here, please* |
| **Question word order** | *What means this box?* → *What does this box mean?* |
| ***Do you have…?*** / ***Is there…?*** | the two questions that unblock a counter |
| **Never leave a box empty** | write *not known* or *not applicable*, in full |

## Unit 5 · The present continuous; repeating back

| | |
|---|---|
| **Continuous** for now and around now; **simple** for always and usually | |
| **State verbs are not continuous** | *know, need, want, mean, understand* |
| **Repeat every name, number and date back** | and spell the name |
| ***She's in a meeting until three*** | a status with no time is not a status |

## Unit 6 · Prepositions of place; *was* / *were*

| | |
|---|---|
| ***in*** inside · ***on*** a surface · ***at*** a point | *at the counter*, *on the shelf*, *in the file* |
| ***was* / *were*** | *the file was here on Tuesday* |
| **Locations run big to small** | room, shelf, box — so the listener can start walking |
| **Say what is *not* there** | *there is no copy in the box* is a finding, not a failure |

## Unit 7 · *going to* and *will*; times and dates

| | |
|---|---|
| ***going to*** for a plan you already have | ***will*** for a decision made as you speak |
| **Present continuous** for a fixed arrangement | *She's arriving at ten past three* |
| ***in*** twenty minutes = after · ***by*** ten = at ten or before | this is how two offices miss each other |
| **Write the month in letters** | and the argument about 03/04 never happens |

## Unit 8 · Numbers, ordinals, *how much* / *how many*

| | |
|---|---|
| **Countable → *how many*; uncountable → *how much*** | *how much documents* |
| **Say a percentage slowly, and say the whole of it** | *nought point nought nought one percent* |
| **A number needs its scale** | the regular budget scale and the peacekeeping scale are two different things |
| **Read every figure back** | one misplaced decimal point is a different country's assessment |

## Unit 9 · The present perfect; *already* / *yet* / *just*

| | |
|---|---|
| **have / has + past participle** | for something done, with the result still true |
| ***already*** before the end · ***yet*** at the end, in questions and negatives | *I have sent it yet* |
| **Past simple needs a finished time** | *I have sent it yesterday* |
| **A document symbol is not a document** | cite the symbol, the date and the revision |

## Unit 10 · *some* and *any*; countable and uncountable

| | |
|---|---|
| ***some*** in statements · ***any*** in questions and negatives | *I don't have some information* |
| ***any*** in a statement means *it does not matter which* | |
| **Uncountable** | *information, advice, news, help* — never *informations* |
| **Three named actions with times** | instead of *we will do everything we can* |

## Unit 11 · Comparatives; *too* and *enough*

| | |
|---|---|
| **short adjective + *-er*; long adjective + *more*** | and the second half is ***than***, not *that* |
| ***too*** + adjective · ***too many*** + countable · ***too much*** + uncountable | |
| ***enough*** after an adjective, before a noun | *long enough*, but *enough days* |
| **Say *maximum* and *apply to enter*** | those two words are the difference between a rule and a promise |

## Unit 12 · Past simple; *would like*

| | |
|---|---|
| **Plain verb after *did* and *didn't*** | *we didn't joined* is the error that lasts longest |
| **Irregular by heart** | become → became · hold → held · write → wrote |
| ***would like* + *to* before a verb** | *I would like check* |
| **Put the complication in the second sentence** | a reader who finds it late thinks it was hidden |

# The British layer

This book is written in American English, and the series carries a switchable British layer: the
spelling of a fixed list of words is swapped at build time, so the same text can be printed in
either variant. Both are correct professional English, and a foreign ministry writes in both --
often in the same week, to different capitals, and sometimes to the same capital in two different
documents. The list of switchable words lives with the series, not in this book, so that the two
printings can never drift apart.

What the layer does not touch, and what you therefore have to get right yourself:

1. **The date.** Write the month in letters. `03/04/2026` is 3 April in one country and 4 March in
   another, and both readers are certain they are right. The layer cannot save you from this,
   because both forms are spelled correctly.
2. **The floor.** In American usage the *first floor* is the one you walk in on. In British usage it
   is the floor above. Say *ground floor*, or give the room number, and the question disappears.
3. **A quoted document keeps its own spelling.** If a treaty, a resolution or a note verbale spells
   a word one way, you quote it that way, inside quotation marks, even when it clashes with the rest
   of your document. Correcting somebody else's spelling inside a quotation is an alteration, and an
   alteration inside quotation marks is a serious thing to be accused of.

Four of the sixteen audio tracks in each unit are recorded twice, once in each variant. The second
recording is the one to use with the British printing.

**Eight honesty notes, printed here because they are printed in the units too.**

- **Joining is not entering into force (Unit 4).** Thailand deposited its instrument on 30 June 2026
  and the Convention enters into force for it on 28 February 2027. A list of parties and a list of
  states for which a treaty is in operation are two different lists, and on any given day they do
  not match.
- **194 is not 193 (Unit 5).** The ITU has 194 member states and the United Nations has 193. Two
  memberships, two organizations, two numbers, and neither is a misprint.
- **A treaty is not a treaty action (Unit 6).** A registration, a ratification, an accession and a
  denunciation are all actions, and one treaty can carry dozens. A count of treaties and a count of
  actions are not comparable figures, and the unit teaches the sentence that says so.
- **The ten-year rule is national law (Unit 3).** ICAO sets the standard for the document. How long
  a passport is valid, and how much validity another state requires on arrival, are decided by
  states, separately, and the numbers differ.
- **Two scales (Unit 8).** The regular budget scale and the peacekeeping scale are built from the
  same base and adjusted differently. Quoting one as the other is the commonest numerical error in
  this field, and it is always in somebody's favor, which is why it gets noticed.
- **A perfect citation can be the wrong document (Unit 9).** A symbol cited exactly, with no
  revision, no `/Add.` and no `/Corr.`, points at a text that has been superseded. The unit teaches
  the symbol, the date and the revision together, because two of the three are not enough.
- **Article 36 is litigated both ways (Unit 10).** The International Court of Justice has found a
  breach of the Article; some domestic courts have held that an individual cannot rely on it
  directly. The unit prints both, because a consular officer who knows only one of them will one day
  say the wrong one in a courtroom.
- **A window that moves (Unit 11).** Ninety days in any one hundred and eighty is counted backwards
  from each day of the stay, so the answer changes every morning. The unit teaches the words *as at*
  and a date beside any figure of this kind.

**Everything else in this book is invented.** Omar Sabbagh, Samira Barakat, Ahmad Rifai, Hana
Darwish, Nadia Shaheen, Yusuf Mansour and Layla Bahri are not real people. Astrand, Perenne,
Marovia, Valmora, Kesteland and the Sable Isles are not real states, and they exist in these pages
precisely so that no real government is given a position it has not taken. Every office, floor,
room number, file reference, form, telephone call, note verbale, case and counter conversation in
this book was written for this book. Nothing here is an official publication of any ministry, and
nothing here carries official status.

# Closing

You began this book able to say your name. You end it able to say your name so that a stranger can
spell it back, give your section and your floor, read a passport page, fill a form with no empty
boxes, take a message somebody else can act on, find a file and say what is missing from it, move a
meeting without losing it, read a percentage out loud without inventing a decimal point, send an
email that cites a document properly, make the first call about a detained national, count ninety
days backwards from today, and tell a school hall the one complicated thing about your country's
seat before anybody in the third row finds it on a telephone.

None of that is advanced English. All of it is the English a ministry runs on at eleven o'clock on
a Tuesday, and almost none of it is taught anywhere.

Three sentences to take with you.

From Unit 3: **I don't know, and I will find out and call you back by four.** It is not a failure. It
is the most professional thing in this book, and every experienced officer says it several times a
week.

From Unit 10: **three named actions with times**, instead of *we will do everything we can*. One
promise you keep is worth more than five that sound better.

From Unit 12: **a card that is easier to say than the truth will be said.** That is why you write
your own cards carefully, and why you say the complicated part first.

Floor three will still be there in Book 2.
