# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it causes, which is
the column worth reading twice.

## Starting Point · Formula, and the three questions

| | |
|---|---|
| **Formula is not decoration** | it lets two ministries that disagree exchange a document without making a new dispute |
| **Four sentences a week** | consent not yet obtained · not in force · the page and its date · we do not print a count |
| **The three questions** | which instrument · are both states parties · as at what date |
| **A number without a page and a date** | is not information, and will be quoted as though it were |

## Unit 1 · Inversion after negative adverbials

| | |
|---|---|
| ***At no point has*** consent been obtained | the auxiliary comes before the subject, every time |
| ***Nor has*** the program been cleared | *nor* inverts; *and not* does not |
| **keep it for the sentence that matters** | three inversions in a note and the reader stops seeing them |
| **consent *previously obtained*** | the Convention's own words; *arranged* is not *obtained* |

## Unit 2 · Participle clauses

| | |
|---|---|
| ***Having deposited*** its instrument, the State became a party | same subject in both halves, or the clause dangles |
| ***Requiring thirty-five instruments*,** the Convention has not entered into force | present participle for the standing fact |
| **a threshold is a number in a clause** | not a target anybody is obliged to reach |
| ***signatory*** is not ***party*** | twenty signatories and thirty-four parties on the same page |

## Unit 3 · Formulaic requests

| | |
|---|---|
| ***I should be grateful if you would*** confirm | the register that cannot give offense |
| ***We should be grateful for*** confirmation **by Thursday** | a request without a date is a wish |
| **ask for the entry, not the opinion** | *please confirm whether your State is a party*, not *are we covered* |
| **162 of 193** | the figure everybody assumes is 193, and 31 states are not parties |

## Unit 4 · Modal perfects

| | |
|---|---|
| ***may have ratified*** / ***must have acceded*** | degrees of inference about a past act |
| ***cannot have been*** a party **in 1980** | the negative of *must have* |
| **never infer a treaty action** | check the entry: inference is for conversation, not for notes |
| **four instruments, four memberships** | 195 · 173 · 167 · 66, each with the date of the map |

## Unit 5 · The future in the past

| | |
|---|---|
| ***was to enter into force*** 180 days after | a future seen from a past point |
| ***would have entered into force*** had the Annex been complete | the counterfactual, kept rare |
| **the clause decides, not the count** | 178 ratifications and not in force |
| **a ratification can be withdrawn** | while the signature remains, which changes the obligation, not the list |

## Unit 6 · Complex noun phrases

| | |
|---|---|
| **the number of High Contracting Parties to the framework convention** | long, and exact, and the only safe form |
| **unpack it before you shorten it** | *the CCW figure* means nothing until you say which figure |
| **protocol by protocol** | 128 framework · 88 to 121 by protocol |
| **a framework is not an obligation** | consent is given protocol by protocol |

## Unit 7 · Conditional inversion

| | |
|---|---|
| ***Were the denominator 193***, the sentence would be true | no *if*, inverted, formal |
| ***Had the entity been eligible***, it would appear on the list | past counterfactual |
| **the denominator is almost never the UN membership** | 193 of 197 is not 193 of 193 |
| ***near-universal*** | an accurate word that a reader hears as *universal* |

## Unit 8 · Impersonal structures

| | |
|---|---|
| ***It is provided that*** access shall be facilitated | the obligation without an accuser |
| ***It is understood that*** the arrangement is provisional | the hedge that does not blame |
| **an obligation has a source** | name the section; courtesy has no section |
| **a dispute clause is a fact about the relationship** | not a threat to quote it |

## Unit 9 · Qualifying markers

| | |
|---|---|
| ***insofar as***, ***to the extent that*** | the limit stated at the front, not in a footnote |
| ***subject to***, ***save that***, ***without prejudice to*** | each one carves out something different |
| ***for the purposes of*** this note | the scope of a definition you are about to use |
| **wrong, provisional and unavailable** | three different things, and only one of them is an error |

## Unit 10 · Fronting for emphasis

| | |
|---|---|
| ***It is the date that*** decides precedence | the cleft, for the one word that matters |
| ***Rarely has*** a short annex outlived its congress | negative adverb, then inversion |
| ***Only by*** recording the date correctly ***does*** it hold | the condition fronted |
| **one per paragraph** | three is a style, and a style is what the reader notices instead of the content |

## Unit 11 · Passive causatives

| | |
|---|---|
| **we *had the lists checked* by the Reference Section** | the work, attributed to whoever did it |
| **we *had the printouts dated*** | the other thing the reader needs, which is when |
| **the figure *has not been verified*** | and the cell is left empty, with a footnote |
| ***taken together*** | the phrase that performs an addition no depositary has performed |

## Unit 12 · Review, and the note verbale

| | |
|---|---|
| **third person throughout** | *the Ministry presents its compliments*; no *we*, no *you*, no signature |
| **one act, one line** | inform · request · transmit · draw attention to |
| **the facts in the enclosure** | figure · column · as-at date · source · who checked it |
| **the formulas never vary** | the day you change the closing, the Embassy spends an afternoon on it |

# The British layer

This book is written in American English, and the series carries a switchable British layer: a fixed
list of words is respelled at build time. The list lives with the series rather than in this book.

What the layer does not touch:

1. **The date.** Write the month in letters.
2. **The floor.** Say *ground floor*, or give the room number.
3. **A quoted instrument keeps its own spelling.** Every convention, agreement and annex quoted in
   this book is quoted as published, inside quotation marks, even where its spelling differs from the
   surrounding text. Correcting an instrument inside a quotation is an alteration.
4. **The title of an instrument is never respelled, translated or abbreviated.** The 1815 Règlement
   keeps its accent. A convention's short title is not a substitute for its date.
5. **A note verbale keeps its formulas exactly.** Both variants use the same opening and the same
   closing, and neither varies them.

**Twelve honesty notes, printed in the units as well as here.**

- **Unit 1.** Sixteen years between adoption and entry into force, and about thirty-eight parties a
  quarter of a century after that. A desk officer who writes *under the Special Missions Convention*
  about a visiting delegation is probably writing about an instrument that binds neither state.
- **Unit 2.** The threshold is thirty-five; the count is thirty-four. One instrument of ratification
  separates a fifty-year-old convention from entry into force, and nothing in the text obliges
  anybody to deposit it.
- **Unit 3.** 162 of 193 is the most useful figure in this book, because it is the one everybody
  assumes is 193. And twenty-three parties accepted the Convention subject to reservations, which has
  to be read state by state.
- **Unit 4.** The Conventions are described as universally ratified and published counts differ by
  one. The Protocols are three further instruments with three smaller memberships, and the figures
  printed here carry the date of the map they came from.
- **Unit 5.** The entry-into-force clause, not the number of ratifications, decides whether a treaty
  is in force. And a ratification can be withdrawn while a signature remains, which puts the law of
  treaties back on the desk.
- **Unit 6.** The framework figure and the protocol figures differ by up to forty. Quoting the
  framework figure as the measure of an obligation is the characteristic error in this field.
- **Unit 7.** 193 out of 197 and 193 out of 193 are different sentences, and only one of them is
  true. The denominator in this field is almost never the UN membership.
- **Unit 8.** A host state's obligations to a headquarters are in a published agreement with a
  dispute-settlement clause. Describing them as hospitality is a mistake in both directions.
- **Unit 9.** A published count that its own publisher's commentators say cannot officially be stated
  is the purest form of this book's subject: the number is not the fact; the page and its date are.
- **Unit 10.** The precedence rule every protocol officer uses began as an annex to the Final Act of
  a congress in 1815, adopted because disputes about rank were producing real incidents. The 1815
  text is not the instrument in force today, and the principle is the same one.
- **Unit 11.** Three instruments on one subject, each with its own party list, and this unit prints
  none of them. The point of the unit is the sentence a drafter writes when the figure is not to
  hand.
- **Unit 12.** The last reading text is the publisher explaining its own table, including the
  language that inclusion implies no position on questions of status or recognition. Everything in
  these four books rests on somebody having read that paragraph.

# Closing

You began this book able to cite an instrument. You end it able to say whether it is in force,
between which states, under which clause, as at which date, from which column, and on whose check —
and, when none of that can be established before five o'clock, to write the sentence that says so.

That last skill is the one this book was built for. Eleven units gave you a published figure and
asked what it did not show. The twelfth showed you that the publisher had said so first, in smaller
type, above the table.

Four sentences to take with you.

From Unit 1: **consent is required and has not yet been obtained.**

From Unit 5: **a hundred and seventy-eight ratifications, and the Treaty is not in force.**

From Unit 9: **where a publisher could not state a figure, we do not supply one.**

And from Unit 12, which is where this book ends: **a ministry is not trusted because its figures are
right; it is trusted because it can say, in one page, how it knows.**
