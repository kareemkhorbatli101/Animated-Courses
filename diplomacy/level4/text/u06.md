**1C  Study the chart.**

| | Example |
|---|---|
| noun + noun | the **framework figure** · a **status page** |
| noun + noun + noun | the **framework party figure** |
| hyphenated premodifier | a **protocol-by-protocol** consent · a **seven-column** table |
| adjective + noun + noun | the **amended protocol party figure** |
| unpacking with **of** / **for** | the figure **for** the parties **to** the framework |
| unpacking with a relative clause | the page **that was last updated** in March |

> **Grammar Note** — Packed noun phrases are formal, compact and hard to read aloud. They belong in
> headings, tables and titles. The moment you need somebody to do something, unpack: *the requirement
> that a state consent separately to each protocol* can be acted on; *the protocol-by-protocol
> consent requirement* has to be decoded first.

### 🌐 CULTURE CHECK

Framework conventions are a drafting invention that solved a real problem and created a reporting
one. They let a state join a structure while it works out whether it can accept a particular
obligation, and they let a new category be added later without reopening a negotiation that took
years. Both of those are genuine achievements. The reporting problem is that the structure produces
one memorable figure and six unmemorable ones, and the memorable one is about attendance. Ministries
quote it because it is high, campaigners quote it because it is high, and nobody is lying. The
discipline is simple and slightly tedious: when the question is about an obligation, answer from a
protocol column; when the question is about participation, answer from the framework column; and when
you do not know which question you have been asked, ask.

**Discuss:** Which figure does your own ministry quote for a framework instrument? Which question
was it answering?
