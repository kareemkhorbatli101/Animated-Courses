# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it causes, which is
the column worth reading twice.

## Starting Point · Six habits

| | |
|---|---|
| **Name the instrument before the answer** | an answer with no instrument in front of it becomes *the ministry said* |
| **Separate the rule from the court** | *I can tell you what the Article says; I cannot tell you what a judge will do* |
| ***I don't know, and I'll find out by*** | the second half is what makes the first half professional |
| **Never guess a rule out loud** | a guessed rule is quoted back as a position |

## Unit 1 · Past simple and past continuous

| | |
|---|---|
| **continuous for the background, simple for the event** | *he was waiting* when *they came over* |
| **state verbs are not continuous** | *he was knowing the name* |
| ***while*** + continuous · ***when*** + simple | |
| **what a document is not, then what it is** | *it is not a warrant. It is an alert.* Both halves, in order |

## Unit 2 · Present perfect with *for* and *since*

| | |
|---|---|
| ***for*** + a length · ***since*** + a starting point | *since five weeks* |
| **a finished time takes the past simple** | *we have sent it last week* |
| ***already*** in the middle · ***yet*** at the end · ***still*** before the negative | |
| **where it is, how long, whose delay** | three facts turn a complaint into a conversation |

## Unit 3 · *must*, *have to*, *be required to*

| | |
|---|---|
| **no *to* after *must*** | *the court must to order return* |
| ***don't have to*** and ***mustn't*** are opposites | one is an offer, the other an instruction |
| ***is required to*** names an instrument | and stops a rule sounding like a preference |
| **say the limit in the first two sentences** | *this does not decide custody* costs five minutes now and a betrayal later |

## Unit 4 · Reported speech

| | |
|---|---|
| **tenses step back** | "I am" → he said he **was** · "I arrived" → he said he **had arrived** |
| ***tell*** needs a person; ***say*** does not | *he told that* · *he said me* |
| **a reported question has statement word order** | *he asked whether we could* |
| **quotation marks are a defense** | his word is his; your conclusion goes under its own heading |

## Unit 5 · The passive

| | |
|---|---|
| **be + past participle** | the birth **was never registered** |
| **no *by* when the doer is unknown** | and never to hide a doer who matters |
| ***can be*** / ***must be*** + participle | a letter **can be written** today |
| **a refusal has three parts** | what cannot be done, who does it, what you can do today |

## Unit 6 · Relative clauses

| | |
|---|---|
| **no commas = defining** | parties **that** reserved · only some of them |
| **commas = non-defining** | the Convention, **which** was adopted in 1989 · all of it |
| ***whose***, ***where*** | a state **whose** reservation was withdrawn |
| **the caveat is shorter than the fact** | a caveat that outruns its fact gets cut |

## Unit 7 · First and second conditionals

| | |
|---|---|
| **no *will* in the *if* clause** | *if the result will come back* |
| ***unless*** = if not | and never *unless… not* |
| ***when*** for certainty, ***if*** for doubt | the other side reads this closely |
| ***if I were you, I would*** | the politest way to advise on somebody else's decision |

## Unit 8 · Articles and quantifiers

| | |
|---|---|
| **no article for uncountables in general** | *evidence takes time* · *assistance is faster* |
| ***a*** first mention, ***the*** afterwards | we received **a** letter. **The** letter asked for two things |
| ***much*** / ***many***, ***less*** / ***fewer*** | *less letters* · *not many evidence* |
| **no plural on *evidence*, *information*, *advice*** | *informations* is the commonest draft error |

## Unit 9 · Verb patterns

| | |
|---|---|
| **verb + *to*** | agree, decide, refuse, undertake, intend |
| **verb + *-ing*** | avoid, consider, involve, risk, suggest |
| **after a preposition, always *-ing*** | *before ratifying* · *without signing* |
| **not X, but Y** | signature is **not** consent to be bound; it **does** carry Article 18 |

## Unit 10 · Future forms

| | |
|---|---|
| **present continuous** for an arrangement | *I am sending it this afternoon* |
| ***going to*** for a plan, ***will*** for a decision now | |
| ***is due to*** = scheduled · ***is to*** = an instruction | *the note is to be attached* |
| ***due to*** + noun = because of | in formal drafting, prefer *owing to* |

## Unit 11 · *although*, *however*, *despite*

| | |
|---|---|
| ***although*** + clause | **although** he has an award… |
| ***despite*** / ***in spite of*** + noun or *-ing* | *despite he won* |
| ***however*** starts a new sentence, with a comma after it | not joining two clauses |
| **number the steps first** | *step one of four*, before any of the bad news |

## Unit 12 · Indirect questions

| | |
|---|---|
| **no inversion** | *could you tell me how long they take* |
| ***whether*** / ***if*** for yes-or-no | *do you know whether the note arrived* |
| **ask what is needed before how long** | or you get a timetable for the wrong thing |
| **request, do not announce** | *we are seeking permission*, never *we will be overflying* |

# The British layer

This book is written in American English, and the series carries a switchable British layer: a fixed
list of words is respelled at build time, so the same text can be printed in either variant. The
list lives with the series rather than in this book, so the two printings cannot drift apart.

What the layer does not touch, and what you therefore have to get right yourself:

1. **The date.** Write the month in letters. `03/04/2026` is 3 April in one country and 4 March in
   another, and both readers are certain they are right.
2. **The floor.** *First floor* means the ground floor in American usage and the floor above it in
   British usage. Say *ground floor* or give the room number.
3. **A quoted instrument keeps its own spelling.** Every treaty article quoted in this book is quoted
   as published, inside quotation marks, even where its spelling differs from the surrounding text.
   Correcting an instrument's spelling inside a quotation is an alteration.

Twelve source bodies carry the twelve reading texts. Not one of them appears in Book Foundation or
anywhere in the two sister series, and no figure is used twice. Every count below is a count on a
published page on a stated date, and every unit prints that date, because these numbers move. The
series note is in `SOURCES.md`.

| Unit | Source | What the text prints |
|---|---|---|
| 1 | INTERPOL's own published pages | **196 member countries** since **2023**, when Palau was admitted as the 196th. **A Red Notice is not an arrest warrant;** it rests on a warrant issued by a national judicial authority, and each member country decides what effect to give it |
| 2 | HCCH, Service Convention of **15 November 1965**, status table | **84 Contracting Parties**, table last updated **21 March 2024**, with the organization's own note that *Contracting Party* covers states for which the Convention **has not yet** entered into force |

**Twelve honesty notes, printed in the units as well as here.**

- **Unit 1.** A Red Notice asks; it does not compel. Published analysis estimates that about a third
  of member countries will treat one as a basis for provisional arrest and the rest require a formal
  request, so the honest answer to *will they arrest him* is a question about which country.
- **Unit 2.** On these status tables *Contracting Party* includes states the Convention does not yet
  bind. The headline count is therefore not the count of states you can serve documents in, and the
  organization says so in small type above the table.
- **Unit 3.** The Convention decides where the custody case is heard, not who wins it. A return order
  is not a custody order, and Article 19 says so in one sentence.
- **Unit 4.** The headline 149 is parties to the Convention *and/or* the Protocol. Quoting it as
  parties to the Convention is wrong by three, and the two instruments do not have the same party
  list.
- **Unit 5.** The 1961 count moved from 78 to 82 in under three years; the commonly quoted 1954
  figure is more than a decade old. The unit teaches *as at* before it teaches either number.
- **Unit 6.** 196 parties is the widest ratification in the human rights field and does not mean 196
  identical sets of obligations.
- **Unit 7.** Everybody remembers the 24 hours. They start after the assessment, which has its own
  48. A text quoting only the 24 has described half the obligation.
- **Unit 8.** A request for evidence and a request for a person are different articles with different
  grounds of refusal, and they are often sent in the same envelope.
- **Unit 9.** Signature is not consent to be bound, and it does carry Article 18. Both halves are
  needed and most speakers drop one.
- **Unit 10.** Two reputable sources give different founding figures. Neither is lying. The unit
  teaches the learner to name the source rather than pick the number they prefer.
- **Unit 11.** 172 counts three parties that are not UN member states; 169 counts only those that
  are. A reader shown the other figure will distrust everything else unless the base was stated.
- **Unit 12.** The Convention's party count and the civil aviation organization's membership are two
  different tallies that sit close together, and one party is a party through a neighbor's
  ratification.

**Everything else in this book is invented.** Omar Sabbagh, Samira Barakat, Layla Bahri, Hana
Darwish, Nadia Shaheen, Ahmad Rifai, Yusuf Mansour, Rashid Nasr and Dalia Khoury are not real
people. Astrand, Perenne, Marovia, Valmora, Kesteland and the Sable Isles are not real states, and
they exist in these pages precisely so that no real government is given a position it has not taken.
Every case, form, file, note, award, flight and telephone call in this book was written for this
book. Nothing here is an official publication of any ministry, and nothing here carries official
status.

# Closing

You began this book able to describe the building you work in. You end it able to tell a case in
order in two past tenses, say where a request has got to and whose delay it is, separate return from
custody in your first two sentences, report a telephone call so accurately that a lawyer can quote it
without quoting you, explain what your office is not able to issue in three parts, give a figure with
the caveat it needs and nothing more, say which of two clocks is running, sort one letter into two
requests before you draft either, say both halves of what a signature does, choose a channel on
purpose, number four steps before you deliver the bad news in any of them, and ask a foreign ministry
for permission at nine at night in a way that gets your call answered in March.

Four sentences to take with you.

From Unit 1: **that is not what that document does.**

From Unit 4: **those are his words, not my conclusion.**

From Unit 9: **signature is not consent to be bound, and it is not nothing.**

And from Unit 12, which is the one this whole book is really about: **everything we are allowed to do
depends on somebody else saying yes, and the only part of that we control is how we ask.**

The desk officer's chair is waiting in Book 2.
