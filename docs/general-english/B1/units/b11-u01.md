> **Notice** Read the Warm-Up again. Find the sentence with *could not*. What was the van doing?

*Figure 1.8 · The past continuous.*

| **The past continuous** | |
|---|---|
| Form | was / were + verb + -ing |
| Use | a longer action, in the middle of happening |
| Example | Amina **was waiting** for a delivery. |
| Not | *I was knowing the answer.* Use *I knew*. |

*Figure 1.9 · One long action, one short one.*

| **Past continuous + past simple** | |
|---|---|
| Form | was / were + -ing … **when** + past simple |
| Use | a short action cuts into a longer one |
| Example | She **was serving** a queue **when** the machine **stopped**. |
| Also | **While** she **was serving**, the machine **stopped**. |

> **Glossary:** **past continuous** — was / were + -ing, for an action in the middle of happening
