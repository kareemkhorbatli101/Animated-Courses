# Irregular Verbs

These verbs do not add **ed** in the past. They become a new word. Learn them
in pairs, and say them out loud.

| Now | Past | Arabic |
|---|---|---|
| be (am, is) | was | كان |
| be (are) | were | كانوا |
| buy | bought | اشترى |
| come | came | جاء |
| do | did | فعل |
| drink | drank | شرب |
| eat | ate | أكل |
| find | found | وجد |
| get | got | حصل |
| give | gave | أعطى |
| go | went | ذهب |
| have | had | كان لديه |
| hold | held | أمسك |
| know | knew | عرف |
| leave | left | غادر |
| lose | lost | فقد |
| make | made | صنع |
| meet | met | قابل |
| say | said | قال |
| see | saw | رأى |
| sleep | slept | نام |
| take | took | أخذ |
| wake | woke | استيقظ |
| write | wrote | كتب |

**Four that look the same:** cost · cut · put · shut. The past is the same
word.

**After did and didn't the verb goes back:** Did you **go**? · I didn't
**see** it. Never *did went*, never *didn't saw*.
