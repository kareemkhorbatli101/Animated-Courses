# 13 · The Scaffolding Spine

The source books scaffold heavily and well — word banks, worked examples, answer frames, phrase
banks, annotated models, finishing checklists. It is their strongest craft feature, and it is kept.

What they do not do is **withdraw it**. An A2 book and a B1 book offer the same supports in the same
density, and Unit 10 is scaffolded exactly like Unit 1. A learner who is still given the word bank
in Unit 10 has not been allowed to find out whether they needed it.

This document specifies the eighteen supports, the withdrawal schedule across the shelf and within
each book, and the sufficiency floor below which a task may not drop.

---

## 1 · The eighteen supports

| # | Support | What it does | Carries the learner over |
|---|---|---|---|
| **S1** | Word bank | Supplies the items a task needs | Retrieval failure |
| **S2** | First letter / letter count | Narrows retrieval without giving it | Partial retrieval |
| **S3** | Sentence stem | Supplies the opening | Blank-page paralysis |
| **S4** | Answer frame | Supplies the shape of a whole response | Discourse-level planning |
| **S5** | Phrase bank, formality-banded | Supplies the functional chunks, sorted by register | Pragmatic failure |
| **S6** | Annotated model | Shows a finished example and the choices inside it | Genre ignorance |
| **S7** | Worked example (`0. is done`) | Models the *thinking*, not only the answer format | Rubric misreading |
| **S8** | Planning frame | Supplies the order of ideas before drafting | Organisation |
| **S9** | Finishing checklist | Two or three things to verify before submitting | Self-monitoring |
| **S10** | Gloss, in place | Defines the item at the point of need | Comprehension breakdown |
| **S11** | Visual support | Supplies the referent | Lexical gap, concept gap |
| **S12** | Role card | Supplies goal, position and constraints | Improvisation under pressure |
| **S13** | Observer sheet | Supplies one named behaviour to notice | Unfocused feedback |
| **S14** | Rubric preview | Shows what will be assessed, before the task | Aiming at the wrong thing |
| **S15** | Peer criteria (two only) | Limits review to what the learner can act on | Overwhelm |
| **S16** | Routing after self-check | Sends a score to a specific page | Not knowing what to do next |
| **S17** | L1 gloss / bilingual note | Supplies the concept in the known language | Conceptual gap |
| **S18** | Delayed transcript | Available after the task, never beside it | Decoding failure without destroying the task |

**Four supports never withdraw** — S13 observer, S15 peer criteria, S16 routing, S18 delayed
transcript. These are not crutches; they are the architecture of self-correction, and a C2 learner
needs them as much as an A1 learner. **S6 annotated models never fully withdraw either**: at C2 the
model is there to be argued with rather than copied.

## 3 · Withdrawal *within* a book

Each book repeats the same gradient in miniature, so that every book ends harder than it began. The
Unit 10 Outcome Task is the Unit 1 Outcome Task with two supports removed.

| | Units 1–3 | Units 4–7 | Units 8–10 |
|---|---|---|---|
| Writing: planning frame | Full frame, six prompts | Three prompts | Headings only |
| Writing: model | Fully annotated | Annotated for two features | Model with the annotations removed |
| Speaking: phrase bank | 11 chunks, banded | 8 chunks, unbanded | 5 chunks, learner adds three |
| Speaking: preparation | Scripted notes | Bullet notes, 3 min | 60 seconds |
| Vocabulary: word bank | All items given | Two-thirds given | Items given with distractors |
| Grammar: worked example | Thinking shown | Answer shown | Example removed, routing kept |
| Decision: answer frame | Four-slot frame | Two-slot frame | Opening clause only |
| Listening: pre-task | Visual + prediction + glossary | Visual + prediction | One question |

The Teacher's Edition prints a **restore line** for every withdrawal: the support that was removed,
and the page it can be reinstated from, for classes that need it. Withdrawal is a default, not a
prohibition.

## 4 · The sufficiency floor

A task may not drop below these minimums. This is the check the brief asks for — *is there enough
scaffolding?* — made countable.

| Task is… | Minimum supports | Of which, at least |
|---|---|---|
| **Receptive, new text** | 2 | one pre-task (S11 or prediction) + S10 gloss |
| **Receptive, decoding clinic** | 2 | S11 visual + S18 delayed transcript |
| **Controlled production** | 2 | S7 worked example + one of S1/S2/S3 |
| **Guided production** | 3 | S6 model + S8 plan + S9 checklist |
| **Open production, written** | 3 | S6 model + S14 rubric preview + S15 peer criteria |
| **Open production, spoken** | 3 | S5 phrase bank + S12 role card + S13 observer |
| **Mediation** | 3 | source + S4 frame + named audience |
| **Decision** | 4 | S4 frame + S5 phrases + S6 model decision + three evidence formats |
| **Evaluate/create at C-level** | 2 | S13 observer + S15 peer criteria (the floor never reaches zero) |

**The floor never reaches zero.** Even a C2.2 open task retains an observer and two peer criteria.
A task with no support is not a hard task; it is an unspecified one.

## 5 · The Scaffolding Load Index

A single number per unit, computed at Gate 1, so that drift is visible across a 14-book shelf
rather than discovered by a teacher.

```
SLI = supports present in the unit ÷ lettered activities in the unit
```

**The denominator is the lettered activity** (`3D`, `11B`, …) — the thing a learner actually does —
**not the task type**, of which a unit carries about 26. A six-stage writing process is six
activities and one task. Both counts are useful; mixing them is what made the first version of this
table wrong.

| Level | Target SLI | Tolerance |
|---|---|---|
| A1 | 2.50 | ±0.35 |
| A2 | 2.10 | ±0.35 |
| B1 | 1.45 | ±0.35 |
| B2 | 1.20 | ±0.35 |
| C1 | 0.95 | ±0.25 |
| C2 | 0.80 | ±0.25 |

> **These targets are measured, not chosen.** The first version of this table carried estimates
> (A1 2.8, B1 2.1) made before any unit existed. When the instrument was built and two finished
> units were run through it, A1.1 Unit 1 came out at **2.52** and B1.1 Unit 1 at **1.45** — the
> second one well outside its asserted target. Rather than pad a sound unit with scaffolding it
> did not need, the curve was re-anchored on what two carefully written units actually produce.
> The *gradient* — A-level roughly 1.7× B-level, B-level roughly 1.8× C-level — is the pedagogical
> claim, and it survived; the absolute numbers were guesses and did not.
>
> The index is sensitive to how activities are counted, so treat it as **a drift detector across a
> shelf, not an absolute measure of quality**. The check that actually protects a learner is the
> sufficiency floor in §4, which is per-task and not negotiable.

Two further checks run alongside it:

- **Within-book gradient.** SLI for Units 8–10 must be **at least 0.3 below** SLI for Units 1–3 of
  the same book. A book whose scaffolding is flat has not taught anyone to work unsupported.
- **Cross-book continuity.** SLI at the *end* of book *n* must be within 0.25 of the SLI at the
  *start* of book *n+1*. This is the check that prevents the cliff a learner feels when they open
  a new book and everything has changed at once.

### Measured — the two pilot units

| | A1.1 Unit 1 | B1.1 Unit 1 |
|---|---|---|
| Visuals | 15 | 12 |
| Word banks | 8 | 8 |
| Sentence stems and gapped frames | 86 | 54 |
| Answer frames | 1 | 2 |
| Phrase banks | 2 | 1 |
| Models and anti-models | 3 | 3 |
| Planning frames | 1 | 2 |
| Checklists and tick-boxes | 38 | 4 |
| Role cards | 2 | 5 |
| Observer sheets | 1 | 1 |
| Peer-criteria boxes | 2 | 2 |
| Routing lines | 1 | 1 |
| Delayed-transcript pointers | 1 | 1 |
| Gloss / Corpus Note boxes | 0 | 1 |
| **Total supports** | **161** | **97** |
| **Activities** | **64** | **67** |
| **SLI** | **2.52** ✔ | **1.45** ✔ |

The shape of the difference is the interesting part. The two units carry almost the same number of
activities, and the A1 unit carries **two-thirds more support** — concentrated in exactly the places
theory predicts: gapped frames (86 against 54) and tick-boxes (38 against 4). The B1 unit spends its
support differently: more role cards, more planning frames, a Corpus Note. That is the withdrawal
schedule in §2 showing up in a measurement rather than in a promise.

## 6 · What is deliberately not scaffolded

- **The Decision's answer.** Frames, phrases and a model decision are supplied; the position is not.
  There is no "correct" option, and the Teacher's Edition says so in those words.
- **The critical response in Reading (R7/R8).** From B1, the learner is asked what the writer left
  out, and no bank of acceptable answers is printed. Teachers get discussion notes, not a key.
- **The Culture File's own-culture half.** Learners describe their own unwritten rules unsupported,
  because supplying them would be the course telling the learner what their culture is.
- **The Part 0 recording.** Thirty seconds, cold, no preparation. Its whole value is that it is
  unscaffolded, so that Part 12's replay measures something real.
