# 15 · Rotation Maps and the Variety Arithmetic

`02` and `06` assert that the series does not repeat itself. This document proves it by counting,
and fixes the rotations that make it true. Four things are checked here:

1. The **File** sections — enough formats, well spread, never repeating inside a book (§1–2)
2. **Reading genres** — ten genres, one per unit, rotated across the shelf (§3)
3. **Listening text types** — mix, settings and speaker configurations (§4)
4. The **task-variety arithmetic** — can 64 types fill 3,600 task slots? (§5)

---

## 1 · The File — 36 formats across 140 slots

### The slot count

| | Books 1–10 (A1–B2) | Books 11–14 (C1–C2) | Total slots |
|---|---|---|---|
| **WORK** | 4 per book → 40 | 3 per book → 12 | **52** |
| **STUDY** | 3 per book → 30 | 4 per book → 16 | **46** |
| **CULTURE** | 3 per book → 30 | 3 per book → 12 | **42** |
| | | | **140** ✔ |

The shelf has exactly 140 Part 9 slots and 140 units. The C-shelf shift (one Work slot becomes a
Study slot) reflects what C-level learners are actually doing: more of them are in or heading for
academic work, and fewer need the basic professional genres they met at B1.

### The 36 formats

The plan as first drafted listed 21 formats, which across 52/46/42 slots would have meant each one
returning **seven or eight times**. That is not a spiral; that is a rerun. Expanded to 36, every
format returns **three or four times across eight years** — roughly once per shelf band, which is
the right spacing for a genuine revisit.

## 2 · File placement within a book

Fixed, so the three strands never clump and no two adjacent units feel the same:

| Book type | U1 | U2 | U3 | U4 | U5 | U6 | U7 | U8 | U9 | U10 |
|---|---|---|---|---|---|---|---|---|---|---|
| **A1–B2** (4W·3S·3C) | **W** | S | C | **W** | S | C | **W** | S | C | **W** |
| **C1–C2** (3W·4S·3C) | **S** | W | C | **S** | W | C | **S** | W | C | **S** |

No File type ever occupies two consecutive units. Each type appears at least once in each third of
the book.

### File internal specification

| | |
|---|---|
| **Extent** | 2 pp (`02-unit-architecture.md` §3), 70 min |
| **Shape** | Stimulus → analysis → production → **transfer** |
| **Stimulus length** | 40% of the unit's 5A reading band (e.g. 100–130 w at B1.1, 200–260 at B2.2) |
| **Realia** | At least one V5 Annotated Realia figure, always |
| **Production** | One deliverable: written, spoken or mediated — never all three |
| **Transfer task** | Compulsory, identical in form every time: *do this in your own workplace, course or community this week, and bring it back* |
| **Culture reciprocity** | Every Culture File examines an English-speaking practice **and** the learner's own, in the same lesson |

The transfer task is the one element that is deliberately identical across all 140 Files. It is the
only part of the course that leaves the room, and its value comes from being a habit rather than a
novelty.

Ten genres for the main text (5A), one per unit, rotated by book so that no genre sits in the same
slot twice running. Rotation uses the same device as the topic domains: step 3 for books 1–10,
step 7 for books 11–14.

| | Genre (5A) |
|---|---|
| **G1** | Feature article |
| **G2** | Personal essay / first-person account |
| **G3** | Report or briefing extract |
| **G4** | Interview transcript |
| **G5** | Review or criticism |
| **G6** | Explainer / how-it-works |

data table · reader's letter · social thread · correction notice · complaint · planning or
administrative notice · FAQ · advertisement · caption set · appendix or footnote. At B1.1 Unit 1
the pairing is **G1 feature + planning notice** — the pairing that makes the critical-response task
in `12-specimen-unit.md` Part 5 work.

## 4 · Listening text types

Per book, per `02-unit-architecture.md` §Part 2:

| Type | Per book | Units |
|---|---|---|
| Monologue (one speaker, sustained) | 4 | 1, 4, 7, 10 |
| Two-person dialogue | 3 | 2, 5, 8 |
| Multi-party, overlapping (3+ speakers) | 2 | 3, 9 |
| Broadcast, podcast or recorded address | 1 | 6 |

**Settings rotate across ten kinds** and may not repeat within a book: a phone call · a meeting ·
an interview · an announcement or tannoy · a voicemail or voice note · a tour or walk-and-talk ·
a lecture or briefing · a vox pop · a radio or podcast segment · an overheard conversation.

**Speaker configuration also rotates**, so that learners are not always listening to two
cooperative people taking turns:

| Configuration | Appears from |
|---|---|
| Two speakers, cooperative, clean turns | A1 |
| One sustained speaker with digressions | A2 |
| Two speakers who disagree | A2 |
| Three speakers, one quiet | B1 |
| Speakers who interrupt and overlap | B2 |
| A speaker being evasive | B2 |
| Degraded audio, line noise, distance | C1 |
| A speaker the listener is meant to find difficult | C1 |

At B1.1 Unit 1 this gives **three speakers, one quiet** — which is why Grace, the quiet one, carries
the inference task in `12-specimen-unit.md` Part 2.

## 5 · The task-variety arithmetic

> Referenced from `06-task-taxonomy.md`. The question: can 64 types fill a 14-book shelf without
> the learner meeting the same exercise twice?

### The slot count

| | |
|---|---|
| Tasks per unit | ~26 (measured on the specimen unit: 26) |
| Units | 140 |
| **Total task instances** | **~3,640** |
| Types available | 64 |
| **Mean uses per type across the shelf** | **~57** |

Fifty-seven uses of each type sounds like a lot until the configuration space is counted.

### The configuration space

Each type is parameterised by the eight difficulty dials in `06-task-taxonomy.md`:

| Dial | Settings |
|---|---|
| Support level | 4 |
| Input length | 6 (one per shelf band) |
| Processing depth | 5 |
| Simultaneity | 4 |
| Preparation time | 4 |
| Answer openness | 3 |
| Interlocutor | 4 |
| Stakes | 5 |

A conservative count of *pedagogically distinct* combinations — most dials are correlated with
level, so the free space is much smaller than the product — is **8–12 meaningfully different
configurations per type per shelf band**, across three bands. That gives roughly **24–36 distinct
realisations of each type** against ~57 uses.

**So types are not the binding constraint; configurations are, and only just.** The honest
conclusion is that a given type will appear in the same configuration roughly twice across eight
years, in books that are typically four years apart. That is acceptable — it is, in fact, desirable
recycling. What would not be acceptable is two near-identical instances in the same book, and that
is what the rules below prevent.

### The four anti-clustering rules

The real risk is not running out of types. It is **slot habit** — the same type always appearing in
the same part, so that Part 1 becomes "the matching page" exactly as it did in the source corpus.

| # | Rule | Checked by |
|---|---|---|
| **R1** | No task type appears twice in the same unit in the same configuration | Gate 1 |
| **R2** | No task type appears in the same Part number in more than **4 of a book's 10 units** | Gate 1 |
| **R3** | Every unit uses at least **6 of the 9 families**; every book uses all 9 in every third of the book | Gate 1 |
| **R4** | No rubric string repeats anywhere in a book; no distractor repeats anywhere in the series | Gate 1 |

R2 is the rule the source books most needed. In EAT, Part 1 contains a definition-match in **10 of
10 units** and Part 5 contains a vocabulary-in-context match in **10 of 10**. Under R2 the ceiling
is 4, and the other six units must reach for L3, L4, L5, L7, L8, L10 or L11 instead.

### Family balance per unit

A unit's 26 tasks distribute roughly like this, and Gate 1 flags any family at zero outside its
permitted levels:

| Family | Tasks/unit | Notes |
|---|---|---|
| L Vocabulary | 5–6 | ≥3, at least one at AN or above |
| G Grammar | 4–5 | G1 guided discovery compulsory; G9 Contrast Clinic compulsory |
| R Reading | 4–5 | R1 compulsory; R7 or R8 compulsory from B1 |
| S Listening | 3–4 | S3 decoding clinic compulsory |
| P Speaking | 3 | one each of fluency, functional, performance |
| W Writing | 3–4 | W1 model deconstruction compulsory |
| M Mediation | 2–3 | at least one from each of the three mediation kinds across a book |
| T Thinking | 2 | T1 Decision + T2 Reveal compulsory; T5 in the File |
| V Visual | 3–5 | one per figure type that carries a task |
