# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it prevents, which is
the column worth reading twice.

## Starting Point · Four numbers that are not progress

| | |
|---|---|
| **What *41 percent* might mean** | time passed · money spent · tasks ticked · **work completed** |
| **Only the fourth is progress** | and most reports mean the first two and are read as the fourth |
| **Three questions a percentage cannot answer** | of what? · measured how, and by whom? · against what was planned by now? |
| **A number with no plan beside it** | is a fact without a verdict |

## Unit 1 · Ratios and indices

| | |
|---|---|
| ***for every* 100 we spend *we get* 78 of work** | a decimal nobody can act on becomes a sentence anybody can |
| **planned · earned · actual** | three numbers; the two indices are derived from them |
| **budget ÷ cost index** | a forecast, which assumes today's index continues |
| **the method of measuring progress** | the standard leaves it to you, and fourteen of our packages score themselves |

## Unit 2 · Progress in time

| | |
|---|---|
| ***as of* a date; *to date*; *elapsed*** | a figure with no date cannot be checked against anything |
| **earned schedule** | read across to the baseline curve and drop a line to the time axis |
| **the money index returns to 1.00 at completion** | on any project, however late; the time index does not |
| **one number for the alarm, another for the address** | a whole-project measure names no activity |

## Unit 3 · Contrast and comparison

| | |
|---|---|
| ***whereas* and *while* take clauses; *unlike* takes a noun** | *unlike the matrix shows controls* is the error of the unit |
| **a matrix screens; a bow tie counts controls** | neither is wrong; they answer different questions |
| **barriers and recovery controls** | one barrier and nothing on the consequence side |
| **the standard describes and declines to recommend** | which leaves the choice, and the decision, with you |

## Unit 4 · The passive with modals

| | |
|---|---|
| **modal + *be* + past participle** | *should be reviewed*, never *should reviewed* |
| **product quality and process quality** | 311 records about the concrete, two about the company |
| **built correctly to the wrong drawing** | every test passed, and the failure was in a way of working |
| **guidance cannot be certified against** | the certificate in the corridor is for something else |

## Unit 5 · Cause and effect

| | |
|---|---|
| ***leads to*, *results in*, *as a result*** | and *because of* takes a noun, *because* a clause |
| **four columns: logic, indicators, sources, assumptions** | and the fourth is the one filled in last |
| **an assumption that cannot be false** | warns nobody; a name and a date make it a question |
| **the result row can succeed while the purpose row fails** | which is the failure the matrix is shaped to predict |

## Unit 6 · *If … then* chains

| | |
|---|---|
| ***if … then*; *only if*; *unless*** | writing *if* where you mean *only if* makes a chain look stronger |
| **the arrows carry the argument** | an arrow drawn between two boxes cannot be false |
| **write each arrow as a full sentence** | and then find the data that tests it |
| **attributable** | *fewer interruptions* was claimed by three projects; one benefit was claimed by one |

## Unit 7 · Shared obligation

| | |
|---|---|
| ***each party shall* + singular verb** | and *neither party may* is singular too |
| ***jointly* and *mutually*** | one document, not two; one owner per row |
| **persons, not posts** | with a rule for what happens when one of them leaves |
| **an exit strategy agreed while things work** | the only morning it can be written is a morning nobody needs it |

## Unit 8 · The present perfect

| | |
|---|---|
| ***have* + participle; *since* a point, *for* a length** | *we have learned that three times* means it is still unlearned |
| **the past simple when the day is named** | *I put it in the template on Tuesday* |
| **a lesson is closed when a document changes** | 212 written, 9 opened, 0 documents changed |
| **retention** | the file copies in an afternoon; the judgment retires in 2027 |

## Unit 9 · Relative clauses

| | |
|---|---|
| **defining takes no comma; non-defining takes commas** | *the figures that are estimates* and *the figures, which are estimates* differ |
| **information need → indicator → derived → base** | follow a number down until you reach somebody collecting something |
| **a method, a scale, a unit and a collector** | *ask the person doing the work* is a method, once it is written down |
| **a number with no method is not ignored** | it is believed by somebody, and the belief is wrong |

## Unit 10 · Time-bound targets

| | |
|---|---|
| ***within* is a limit; *in* is a promise of a time** | in a continuity document that is the whole commitment |
| ***no later than*, *at least once a year*** | a commitment with no date is an intention |
| **a review reads a document; an exercise asks it to be true** | six people, one table, and *and then what* after every line |
| **two correct documents in two organizations** | two hours and two days, never read side by side |

## Unit 11 · Indirect effects

| | |
|---|---|
| ***leads people to*; *end up* + *-ing*; *has the effect of* + *-ing*** | grammar that describes behavior without accusing anybody |
| **a median can improve while the tail gets worse** | 11 → 6 days, and 14 → 23 at the ninetieth percentile |
| **two numbers on one line** | one number turns into a target; two opposed ones cannot be resequenced |
| **the famous sentence is Strathern's, 1997** | Goodhart's own 1975 claim was narrower and about monetary aggregates |

## Unit 12 · Review

| | |
|---|---|
| **twelve lines, one page, ninety seconds** | every figure with its method and its collector |
| **mark the weak lines** | the two asterisks are what make the other ten believable |
| **a clause can sit unread for eleven years** | in a standard a company is proud of, with correct audits throughout |
| **read the limits, not the titles** | which is the whole method of all three books |

# The British layer

This book is written in American English, and the series carries a switchable British layer: a fixed
list of words is respelled at build time. The list lives with the series rather than in this book.

What the layer does not touch:

1. **The date.** Write the month in letters where the sentence is prose, and the international format
   where it is data.
2. **A quoted document keeps its own spelling.** Every standard, paper and guideline quoted here is
   quoted as published. Correcting a published document inside a quotation is an alteration.
3. **A document number keeps its published form.** ISO 21508:2018, IEC 31010:2019, ISO 44001:2017
   and ISO/IEC/IEEE 15939:2017 are citations, not words.
4. **Money has no symbol anywhere in this series.** The unit is whatever currency your project
   uses.
5. **A name is never respelled.** Lipke, Flyvbjerg, Goodhart, Strathern and Campbell are spelled as
   they are published.

**Programme** keeps that spelling throughout, as in Books 1 and 2: it is the term ISO 21506:2018
defines and ISO 21503:2022 uses. The European Commission guidelines quoted in Unit 5 use the same
spelling, which is convenient and is not the reason.

# Sources

Twelve source bodies carry the twelve reading texts, one per unit, and the Starting Point carries
none. Every one is a published standard, paper or set of guidelines, cited with its edition or date,
and every reading text prints what the publisher or the author says the document does **not** cover.
No source appears in any other book of this series or in its four sister series, and no figure is
used twice. The series note is in `SOURCES.md`.

| Unit | Source | What the text prints |
|---|---|---|
| **1** | **ISO 21508:2018**, *Earned value management in project and programme management* | Guidance, not for certification: no thresholds for action, no method for measuring physical progress, no reporting frequency; results depend entirely on the baseline |
| **2** | **W. Lipke**, *Schedule is Different*, **The Measurable News, 2003** | A technique in a practitioners' newsletter, not a standard; it inherits the baseline and the progress measurement, names no individual late activity, and its forecast assumes present performance continues |
| **3** | **IEC 31010:2019**, *Risk management — Risk assessment techniques*, replacing ISO/IEC 31010:2009 | It describes techniques and their limitations without prescribing which to use; many need data or expertise that may be unavailable; and it states that risk assessment supports a decision rather than replacing it |
| **4** | **ISO 10006:2017**, *Quality management — Guidelines for quality management in projects* | Guidance, not for certification and not a management system standard; it specifies no product quality requirements and does not describe how to manage a project |
| **5** | **European Commission**, *Aid Delivery Methods, Volume 1: Project Cycle Management Guidelines*, **March 2004** | Written for external assistance programmes, not commercial projects; it warns against mechanical application, requires verifiable indicators without a test of verifiability, and shows one logic without the rejected alternatives |
| **6** | **W. K. Kellogg Foundation**, *Logic Model Development Guide*, **2004** | A practical guide for non-profit programmes, not a project standard; it displays a theory of change and provides no test of it; it notes that outcomes are often outside the programme's control |
| **7** | **ISO 44001:2017**, *Collaborative business relationship management systems — Requirements and framework*, replacing BS 11000-1:2010 | Certifiable, but certification concerns the system and not the relationship; it does not address contract terms, dispute resolution or the alignment of the parties' commercial incentives |
| **8** | **ISO 30401:2018**, *Knowledge management systems — Requirements* | Certifiable; it distinguishes knowledge management from information and document management; it prescribes no tools, taxonomies or methods and does not determine what knowledge to retain |
| **9** | **ISO/IEC/IEEE 15939:2017**, *Systems and software engineering — Measurement process* | It defines a process and an information model and prescribes no measures; it does not determine which information needs matter; and it cannot establish whether a measure validly represents what you care about |
| **10** | **ISO 22301:2019**, *Security and resilience — Business continuity management systems — Requirements*, replacing the 2012 edition | Certifiable; it sets no recovery time objectives and prescribes no solution, does not address project delivery risk, and certification concerns the system rather than any plan's effectiveness |
| **11** | **C. A. E. Goodhart, 1975**, *Problems of Monetary Management: The U.K. Experience*; and **M. Strathern, 1997**, *"Improving ratings": audit in the British University system*, European Review | Goodhart's claim concerns monetary aggregates; the popular phrasing is Strathern's, from an article on university audit; a related formulation is Campbell's, 1979; neither addresses project measurement and neither offers a remedy |
| **12** | **ISO 9001:2015**, *Quality management systems — Requirements*, clause 9 | It specifies the inputs a management review must consider and no format, length, frequency or particular measures; it addresses the management system rather than any project |

Twelve admissions, one per unit, worth reading as a list of their own.

- **Unit 1.** The arithmetic of earned value is flawless and everything uncertain has already
  happened by the time the division is done. Fourteen of thirty-eight packages scored themselves,
  twelve points high.
- **Unit 2.** The schedule index improves as a project gets later and reads 1.00 on the last day of
  the latest project in the company's history. The repair is three lines of arithmetic that nobody
  had done in eleven years.
- **Unit 3.** The matrix was not wrong. It answered the question it is built for, and the risk it
  ranked fourth had one barrier and no recovery control.
- **Unit 4.** Three hundred and eleven records about the concrete and two about how the company runs
  projects — because one of those things can be certified and the other cannot.
- **Unit 5.** *Stakeholders remain supportive* cannot be false, which is worse than being wrong. One
  rewritten line found ninety thousand of somebody else's work in four days.
- **Unit 6.** The funding case rested on the one arrow that the client's own log contradicted, and
  the project was still worth building for a sentence nobody had written down.
- **Unit 7.** Two competent companies managed the same risk in opposite directions for four months,
  with nothing hidden, because the two registers had never been in the same room.
- **Unit 8.** Two hundred and twelve lessons, nine openings, no document changed. The destination was
  wrong, not the intention.
- **Unit 9.** Two numbers on a board report traced to nothing at all, and one reader had been quietly
  treating one of them as a fact about resignations.
- **Unit 10.** A continuity plan read perfectly for six years with a seized valve in the middle of
  it, because a review reads a document and an exercise asks the document to be true.
- **Unit 11.** All four measures were met. The best measure in this course distorted the work within
  nine months, and the famous sentence about it is by the wrong author in its famous form.
- **Unit 12.** A clause two pages long, in a standard the company is proud of, went unread for eleven
  years, with every audit correct throughout.

# A note on everything else in this book

Every person, team, company, project, number and incident in this book is invented. Lindhurst does
not exist; neither do the harbour pump station, the Ridgeway estate, the depot, the nineteen finished
stations, the two hundred and twelve lessons or any of the eighteen people who appear in the
dialogues. The documents are real and cited; the stories around them are written to teach the
language.

Nothing in this book is legal, financial or contractual advice. Where a sentence sounds like a rule
— *a lesson is closed when a document changes*, *two numbers on one line*, *freed no later than 14
April* — that is one invented company's internal practice, printed because a concrete number teaches
better than an abstraction. Your own numbers belong to you and your sponsor.

# Closing

You began this book able to say that a project was forty-one percent complete. You end it able to
say **percent of what**, **measured how and by whom**, **against what was planned by now**, **how
many weeks that is**, **what stands between you and the top risk**, **who will measure the benefit
and in which year** — and which line of your own report you would not defend.

Twelve documents, and one habit: **follow every number down until you reach a person collecting
something, and print what you find beside it.**

Six sentences to take with you.

From Unit 1: **percent of what, and measured how?**

From Unit 2: **how many weeks, as of when?**

From Unit 3: **what stands between us and this?**

From Unit 5: **who could confirm that, and by when?**

From Unit 10: **has it ever been exercised?**

From Unit 11: **and what is the second number?**

That last question is the one this book would keep if it could keep only one. Every measure in these
twelve units was met, and the ones that were met most convincingly are the ones that moved the work
somewhere nobody had chosen.
