# Starting Point · What a Project Is

Some work has an end. Some work does not. A project is the first kind, and almost everything in this
book follows from that one difference.

### 1 · Six things you already have

%%FIG pa00-f1 | A single review sheet with six boxes. Each box has a heading — the present simple, the past simple, numbers, dates, there is and there are, and questions — and one short example sentence from a project meeting.%%

**1A  Read the six examples aloud with a partner. Which two do you use most?**

| | |
|---|---|
| **The present simple** | The team **meets** every Monday. |
| **The past simple** | We **finished** the design in March. |
| **Numbers** | Fourteen people. Twelve weeks. A budget of 240,000. |
| **Dates** | **On** 9 March. **In** April. **By** Friday. |
| **There is / there are** | **There are** four risks on the register. |
| **Questions** | **When** will it be ready? **Who** decides? |

### 2 · Work with an end, and work without one

%%FIG pa00-f2 | Two columns side by side. The left column is headed a project and lists four lines; the right column is headed ordinary work and lists four different lines; an arrow at the foot points to a box reading one of these has a last day.%%

**2A  Read the two columns. Then say three examples of each to your partner.**

| A project | Ordinary work |
|---|---|
| It has a start and an end. | It continues. |
| It makes something new. | It keeps something running. |
| The team comes together, then goes. | The team stays. |
| It has a budget for the whole thing. | It has a budget every year. |

A new water pump station is a project. Running the water company is not. Both are real work and both
need good people. **This book is about the first one.**

### 3 · Four questions about any piece of work

%%FIG pa00-f3 | A card taped inside a notebook, printed with four questions in bold, each with one line of smaller type under it saying who asks it.%%

**3A  Read the four questions. Then ask your partner all four about their own work.**

> **1  What are we making?**
> *The client asks this first, and the answer is usually too long.*
>
> **2  When will it be finished?**
> *Everybody asks this. Very few people say "by which date, exactly".*
>
> **3  What will it cost?**
> *The sponsor asks this. The answer is a number and a date.*
>
> **4  Who decides?**
> *Nobody asks this until something goes wrong.*

The fourth question is the one this book returns to. **A project with no answer to question four has
a problem it has not met yet.**

### 4 · Two ways of answering question two

%%FIG pa00-f4 | Two speech bubbles, one above the other. The first says soon. The second gives a date, a condition and a name, with three short lines beneath it.%%

**4A  Read the two answers. Then discuss: which one does your team give?**

| | |
|---|---|
| **Answer 1** | "Soon. Before the summer, I think." |
| **Answer 2** | "The 14th of June, if the pumps arrive in week 12. Ahmad is checking the pumps today." |

Both answers are honest. Only the second one can be checked, and only the second one tells the
client what to worry about. **Everything in Lesson 5 of every unit is practice for the second
answer.**
