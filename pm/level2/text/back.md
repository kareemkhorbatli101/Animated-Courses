# Grammar reference

Every structure in this book, in unit order. The second column is the mistake it prevents, which is
the column worth reading twice.

## Starting Point · What a date rests on

| | |
|---|---|
| **Four things a date can rest on** | somebody did it before · somebody who will do it agreed · arithmetic · somebody needs it |
| **The fourth is not an estimate** | it is a requirement wearing an estimate's clothes |
| **An estimate and a promise are different sentences** | one can be wrong without anybody breaking a word |
| **One number is almost never the answer** | *twelve weeks* hides what the speaker is worried about |

## Unit 1 · Dependencies and *until*

| | |
|---|---|
| **cannot start until** | and *until it passes* is eleven days from *until it is done* |
| **after *until*, *once*, *as soon as*: present tense** | *as soon as it **is** approved*, never *will be* |
| **float is a number** | 41 days on the fence, nought on the valves |
| ***critical* means no float, not risky** | a two-day task on the path can be worse than a ten-week one off it |

## Unit 2 · Ranges and approximation

| | |
|---|---|
| **between … and · at best · at worst** | three numbers, and a condition on each end |
| **(a + 4m + b) ÷ 6** | exact arithmetic on inputs nobody has checked |
| **a worst case is a story** | if you cannot tell the story, it is the middle with a margin on it |
| **merge bias** | three chains at 90 percent give a milestone at about 73 |

## Unit 3 · The zero conditional; *tends to*

| | |
|---|---|
| **if** + present, present | *if you give it four weeks, it **takes** four weeks* |
| ***tends to*, *as a rule*, *usually*** | a tendency stated as a certainty is a different claim |
| **work and named waiting** | twelve days of work plus eight days with somebody's name on them |
| **adding a page is free; removing one needs nerve** | which is why a pack only ever grows |

## Unit 4 · Reported speech

| | |
|---|---|
| ***said* takes no person; *told* needs one** | *he said me* is the error of this unit |
| ***will* → *would*, present perfect → past perfect** | reporting a date fairly means reporting when it was said |
| **the inside and the outside question** | *how long will it take* and *how long did the last four take* |
| **the same people answer them differently** | five weeks and eight weeks, one afternoon, no change of mind |

## Unit 5 · Comparatives with data

| | |
|---|---|
| **22 percent higher **than what**** | a percentage with no base is not a number |
| **twice as … as · by a factor of · compared with** | the ways to put two figures beside each other |
| **the three steps** | choose the class · find the distribution · place your project |
| **step one is an argument** | everything after it is arithmetic |

## Unit 6 · Percentages and increase

| | |
|---|---|
| ***by* gives the change; *to* gives the level** | *increased by 44 percent* and *increased to 44 million* |
| **start at the upper bound and argue down** | with evidence, in writing, in front of somebody |
| **an uplift is not a contingency** | it corrects a forecast; it funds nothing |
| **one word can be worth 530,000** | *standard* or *non-standard*, argued at the gate |

## Unit 7 · *The more … the more*

| | |
|---|---|
| **both halves take *the* + comparative** | and neither half takes *will* |
| **pairs, not people** | six people make fifteen pairs; ten make forty-five |
| **the ten-second test** | would two pieces of this work ever need to agree? |
| **subtract a task, do not add a person** | one clean piece with one owner is help; four extra hands are company |

## Unit 8 · The first conditional

| | |
|---|---|
| **if** + present, **will** | and *in case* never takes *will* either |
| ***shall not* and *need not* are opposites** | one forbids; one releases |
| **buffer, not blame** | a missed fifty-fifty estimate is buffer used, with no name |
| **the rule goes above the numbers** | below them it reads as an excuse written afterwards |

## Unit 9 · Modals for documents

| | |
|---|---|
| ***shall* requires · *should* recommends · *may* permits** | translating one as another changes the document |
| **conformance is about content, not accuracy** | a plan can conform in full and be wrong in every number |
| **a heading is not a warning** | four blank sections, and one of them held the five weeks |
| **every section needs an owner** | which is not in the standard, and had to be |

## Unit 10 · Purpose clauses

| | |
|---|---|
| ***to* and *in order to* take a verb; *so that* takes a clause; *for* takes a noun** | *for to save time* is the error of this unit |
| **output · outcome · benefit** | the thing, the change, and the measurable good |
| **a benefit needs a number, a date and a name** | and the name is usually in somebody else's organization |
| **could not achieve separately** | the test for whether a group of projects is a programme |

## Unit 11 · Quantifiers

| | |
|---|---|
| ***none of* and *neither of* take a singular verb** | *none of the three **was** stopped* |
| ***fewer* counts; *less* measures** | fewer projects, less capacity |
| **demand and capacity, both as numbers** | twenty-two and sixteen, on one slide |
| **the third option** | be short on purpose, in November, with a name on it |

## Unit 12 · Review

| | |
|---|---|
| **page one** | chain · range · class · money · buffer · capacity |
| **page two** | every assumption, with a name and a date |
| **page two is the deliverable** | it is the only page that creates work for other people |
| **a claim nothing can disprove tells you nothing** | which is why the best-written source is not in the plan |

# The British layer

This book is written in American English, and the series carries a switchable British layer: a fixed
list of words is respelled at build time. The list lives with the series rather than in this book.

What the layer does not touch:

1. **The date.** Write the month in letters where the sentence is prose, and the international format
   where it is data.
2. **A quoted document keeps its own spelling.** Every standard, paper, column, book and guidance
   note quoted in this book is quoted as published. Correcting a published document inside a
   quotation is an alteration.
3. **A document number keeps its published form.** ISO/IEC/IEEE 16326:2019, ISO 21503:2022 and
   ISO 21504:2022 are citations, not words.
4. **Money has no symbol anywhere in this series.** The unit is whatever currency your project uses.
5. **A name is never respelled.** Kelley, Walker, Parkinson, Buehler, Griffin, Ross, Flyvbjerg,
   Brooks, Goldratt and Hofstadter are spelled as they are published.

**Programme** keeps that spelling throughout, in the American edition as well as the British one.
It is the term **ISO 21506:2018** defines and **ISO 21503:2022** uses, and *program* is a different
word in that vocabulary. The one exception is **PERT**, whose own name is *Program Evaluation and
Review Technique*: a title is quoted as published, even when it disagrees with the page around it.

# Sources

Twelve source bodies carry the twelve reading texts, one per unit, and the Starting Point carries
none. Every one is a published standard, paper, column, book or guidance note, cited with its
edition or its date, and every reading text prints what the publisher or the author says the
document does **not** cover. No source appears in any other book of this series or in its four
sister series, and no figure is used twice. The series note is in `SOURCES.md`.

| Unit | Source | What the text prints |
|---|---|---|
| **1** | J. E. Kelley Jr. and M. R. Walker, *Critical-Path Planning and Scheduling*, Eastern Joint Computer Conference, **December 1959** | It computes the longest route from what it is given; one fixed number per activity, no uncertainty, no resources in its original form, and no judgment about whether the dependencies are real |
| **2** | *PERT Summary Report, Phase 1*, Special Projects Office, Department of the Navy, **July 1958** | The weights follow from a distribution assumed for ease of hand computation; the spread is modeled along one path and not across merges; and the claimed time savings on Polaris were questioned by Sapolsky in 1972 |
| **3** | C. Northcote Parkinson, *Parkinson's Law*, **The Economist, 19 November 1955**; book edition 1958 | A satirical essay about the growth of administrative staff, not the duration of tasks; it offers no measurement and does not claim work can be done in any period chosen for it |
| **4** | R. Buehler, D. Griffin and M. Ross, *Exploring the "planning fallacy"*, **Journal of Personality and Social Psychology, 1994** | It measured individuals predicting their own academic tasks, not project teams, and offers no corrected figure to use instead |
| **5** | B. Flyvbjerg, *From Nobel Prize to Project Management: Getting Risks Right*, **Project Management Journal, August 2006** | It needs comparable completed projects with recorded outturns, gives a distribution rather than a cause, leaves the choice of class as a judgment, and does not address deliberate misrepresentation |
| **6** | Supplementary guidance on **optimism bias** issued with a government treasury's appraisal green book, first published **2003**, based on a **2002** review of fifty projects | The percentages are upper bounds to be argued down with evidence; they come from one country's public projects of that period; the guidance is about appraisal, not delivery, and offers no test of whether a project is standard |
| **7** | F. P. Brooks Jr., *The Mythical Man-Month*, **Addison-Wesley, 1975**; anniversary edition 1995 | Essays from experience rather than a controlled study, stated for software projects, with no formula for team size or training cost, and applying only to work that cannot be partitioned without communication |
| **8** | E. M. Goldratt, *Critical Chain*, **North River Press, 1997** | A business novel; its support is anecdotal and case-based, the fifty-per-cent cut is a rule of thumb, buffer management depends on honest remaining durations, and it does not address contractual dates |
| **9** | **ISO/IEC/IEEE 16326:2019**, *Systems and software engineering — Life cycle processes — Project management* | It specifies the content of a plan and prescribes no length, format or detail; it is written for systems and software work; and conformance concerns the document, not the accuracy of the plan |
| **10** | **ISO 21503:2022**, *Project, programme and portfolio management — Guidance on programme management* | Guidance, not for certification: no structure, roles, size or method, no threshold for when work should be a programme, and no method for measuring benefits |
| **11** | **ISO 21504:2022**, *Project, programme and portfolio management — Guidance on portfolio management* | Guidance, not for certification: no selection method, no scoring model or weights, no portfolio size; alignment required without defining the objectives; and nothing on the consequences of stopping a component |
| **12** | D. R. Hofstadter, *Gödel, Escher, Bach: An Eternal Golden Braid*, **Basic Books, 1979** | A self-referential joke inside a book about mathematics and mind: not a study, no method, no measurement, and unfalsifiable by construction, so no guidance for action |

Twelve admissions, one per unit, worth reading as a list of their own.

- **Unit 1.** The arithmetic has been perfect since 1959 and it has never once asked whether the
  dependencies it was given are real. Nine activities with no predecessor and five weeks disappear.
- **Unit 2.** The weights in the most famous estimating formula in the world were chosen because
  somebody had to do the sums by hand in 1958.
- **Unit 3.** A satirical column about naval office staff is quoted at welders, by people whose own
  reporting pack has grown from four pages to thirty-one.
- **Unit 4.** The students' own worst case was beaten, on average. The paper measures how wrong
  people are and does not tell you what number to use.
- **Unit 5.** Everything after step one is arithmetic, and step one is choosing which projects count
  — which is also the easiest place to produce the answer you wanted.
- **Unit 6.** Fifty projects, one country, twenty years ago, and still the most useful number in the
  paper, because it is the one you must argue away from in public.
- **Unit 7.** A book of essays about 1960s software explains both halves: why four detailers made a
  drawing package later, and why three crews made a fence three times faster.
- **Unit 8.** A novel. The arithmetic took an afternoon; what made it work was one sentence signed
  before anybody was asked for a number.
- **Unit 9.** A plan can contain all fourteen required sections, conform completely, and be wrong in
  every figure it holds. The requirement a standard can test is whether a subject is addressed.
- **Unit 10.** The guidance asks for a benefit with a number, a date and an owner — and the owner is
  usually in another organization and has to agree to be named.
- **Unit 11.** Three projects stopped in six years, none of them at a review. The guidance says a
  portfolio should be balanced against capacity and says nothing at all about the meeting.
- **Unit 12.** The best-written source in the book cannot be disproved by anything, which is exactly
  why it is in the back matter and not in the plan.

# A note on everything else in this book

Every person, team, company, project, number and incident in this book is invented. Lindhurst does
not exist; neither do the harbour pump station, the Northgate programme, the Ridgeway estate, the
nineteen finished stations, the two welders or any of the sixteen people who appear in the
dialogues. The documents are real and cited; the stories around them are written to teach the
language.

Nothing in this book is legal, financial or contractual advice. Where a sentence sounds like a rule
— *a missed fifty-fifty estimate is buffer, not blame*, *44 percent reduced to 12*, *two pages* —
that is one invented company's internal practice, printed because a concrete number teaches better
than an abstraction. Your own numbers belong to you and your sponsor.

# Closing

You began this book able to say that a project would take twelve weeks. You end it able to say
**between which two numbers**, on **which conditions**, compared with **which finished jobs**, with
**which published uplift argued down by what evidence**, protected by **which buffer under which
written rule** — and which assumptions nobody has yet confirmed, with a name and a date beside each
one.

Twelve sources, and one habit: **put a number and a name next to everything, and keep what actually
happened.**

Six sentences to take with you.

From Unit 1: **what cannot start until what?**

From Unit 2: **tell me the story of the worst case.**

From Unit 4: **how long did the last four take?**

From Unit 6: **by how much, and to what level?**

From Unit 8: **what happens to me when I miss it?**

From Unit 12: **which line has nobody's name on it?**

That last question is page two. Four of the eleven lines had no name when it was first written, and
one of those four was false — which is the only reason this book exists in the form it does.
