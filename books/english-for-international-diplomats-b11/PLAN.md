# English for Foreign Ministry Staff Members (B1.1) — International Edition

An exact structural twin of the Syrian B1.1 Student Book, transposed so that
every unit is set in a different non-English-speaking country.

The source is the full B1.1 edition: five units, thirty-six exercises each, a
complete answer key and a complete audio-script appendix. It is a larger and
richer book than the B1 simplified edition — 3,604 elements against 1,983, and
71,241 words against 43,522 — built on the same design system with fourteen
additional element types.

### What the B1.1 edition adds over the B1 simplified edition

- **Completable grids.** 2B and 8B carry a real table whose empty cells are
  shaded `F0F0F0` for the student to fill, with a bordered `Choices:` box of
  lettered options underneath.
- **Verb prompts.** Guided Practice gives the infinitive in brackets —
  `____ (work)`.
- **Ruled answer lines.** Error Correction prints a `BBBBBB` rule under every
  sentence; the phrase box prints five numbered rules.
- **Real multiple choice.** 3C is now a 🔊-prompted stem in a pale blue box
  with a) and b) options beneath it, rather than two bare lines.
- **Language in Context (5C).** Six numbered collocation items, each a gap
  sentence followed by a bordered four-option `Word list:` strip.
- **Word lists in Part 6.** Every model document now carries its own
  `Word list:` strip.
- **Spoken Sample Answers.** Twenty-six answers in the key are followed by a
  green-ruled model dialogue, colour-coded by speaker.
- **A complete audio appendix.** All 61 tracks are transcribed, not just one
  per unit.
- **B1 Target / B2 Extension.** The answer key's two tiers are relabelled.

## 2 · The transposition

The source is set entirely in Syria. The twin moves each unit to a different
non-English-speaking country, on five continents, and keeps every structural
feature of the source.

| unit | country | ministry | principal cast |
| --- | --- | --- | --- |
| 1 | **Viet Nam** | Hanoi | Linh Nguyen (reception), Pham Thi Mai (protocol), Nguyen Van Duc (consular), Tran Thu Ha (press), Le Quang Huy (economic) |
| 2 | **Morocco** | Rabat | Salma Benali (liaison), Youssef El Amrani (economic), Nadia Tazi (protocol) |
| 3 | **Colombia** | Bogotá | Valentina Restrepo (press attaché), Andrés Gaviria (economic affairs) |
| 4 | **Kazakhstan** | Astana | Aigerim Dosanova (protocol), Daniyar Suleimenov (economic affairs), Zarina Abenova (press) |
| 5 | **Ethiopia** | Addis Ababa | Selamawit Tesfaye (investment facilitation), Dawit Bekele (economic affairs), Meron Haile (legal) |

Visiting counterparts are drawn from Germany, France, Japan, Türkiye, Korea,
Brazil, Norway, Italy, Belgium, Romania, Thailand, Senegal, India, Indonesia,
Spain, Finland, the Gulf states and the UN system — so each unit's cast is
international, and no two units repeat a partner profile.

The warm-up of each unit speaks of "your country" and "the Ministry", exactly
as a course used in more than one ministry must; the body of each unit names
its country. The grammar syllabus is unchanged: Present Simple and Continuous
(U1), modal verbs (U2), the passive voice (U3), future forms (U4), conditionals
and investment language (U5).

## 3 · Fidelity criteria

The twin is held to the source on all of the following. Each is checked by a
script in `qa/`, not by eye.

1. Same element count in reading order, section by section.
2. Same paragraph style, shading, border colour, border weight and border sides.
3. Same indent, left and right.
4. Same `before`, `after` and `line` spacing on every paragraph.
5. Same page breaks, in the same places.
6. Same list membership and list format.
7. Same run structure inside every paragraph: bold, italic, underline, colour,
   size, shading, and where the text is split between runs.
8. Same table count, row count, cell count and column widths.
9. Same grid shading: blue header, white body, grey cells to complete.
10. Same number of instruction boxes, part bars, dialogue bars, answer blocks,
    reading panels, track heads, audio chips, play notes and document heads.
11. Same number of fill-in blanks, ruled lines and numbered rules.
12. Same 🔊 and 📝 counts.
13. Same blank-spacer count.
14. Same female- and male-voice line counts.
15. Same 36-exercise template, part by part, in every unit.
16. Same exercise labelling scheme, including the double space after the colon.
17. Same audio-track numbering and the same track-to-exercise mapping.
18. Word count within 1 % overall and within 2 % in every section.
19. Per-answer length parity in Appendix B.
20. Page count within one page, and the same section opening pages.

## 7 · Three deliberate divergences

The source's three **Noticing Grammar** exercises (2A in Units 2, 3 and 4) each
carry an instruction telling the student to look at the target forms *in bold* —
"Pay attention to the modal verbs in bold", "Notice the sentences in bold" — but
the source's own memo and press-release text has no bold runs at all, so the
exercise cannot be done as written.

The twin bolds the modal verbs, the passive constructions and the future forms
that each instruction points at. These are the only three paragraphs in the book
whose run structure differs from the source, and they are listed here rather
than silently normalised.

## 8 · Source quirks reproduced rather than normalised

1. Every unit title is printed twice — `Unit 1: Unit 1: Welcoming the World …` —
   in the unit head, the Appendix B head and the Appendix A head alike.
2. Exercise labels carry a double space after the colon (`W-A:  Pair Discussion`).
3. `Heading3` is applied to exercise heads together with a second, undefined
   style, so Word renders them as body text. Reproduced exactly.
4. Appendix B numbers exercises 1–36 sequentially while the units label them
   `W-A` … `8E`; the answer key therefore skips the unanswered numbers.
5. Units 2 and 3 answer Exercise 11 (Error Correction) with a `Question 4`
   sample answer *above* the answer table rather than below it.
6. The answer-key strip tables size their columns from the number of answers
   rather than from the five slots they lay out, so a four-answer strip has
   25 %-wide cells and a three-answer strip 33.33 % ones, with the padding cells
   left at a borderless 20 %.
7. Appendix A colours the speakers of Track 4.2 `~ ^ ~ ~` while Appendix B
   colours the same dialogue `^ ^ ^ ^`.
8. The word-bank table carries a `<w:pStyle w:val="[object Object]"/>`, a
   leaked JavaScript object from whatever generated the source. Kept verbatim.
9. `docDefaults` is empty — no default size, no default spacing. Setting them
   inflates the page count by about 8 %, so the twin leaves them empty too.
10. The Thinking Guide lines sit at indent 360 at 11 pt rather than with the
    arrow bullets they follow.
11. Appendix A's centred note uses `after=200` while Appendix B's uses `after=400`.
