@INSTR Read about root cause logic.
_80
@NUM 100
1. Read: "Root cause logic explains the relationship between an action and the result expected from it. It shows how an action is supposed to remove a cause. For example, if we log the report on the day it arrives, the register is complete. If the register is complete, the case can be closed at once. If cases are closed at once, sites stop chasing. If sites stop chasing, the post has time for the work itself. Root cause logic helps staff understand the path from one action to the long-term result."
            According to the text, does having clear root cause logic eliminate patrol risk?
