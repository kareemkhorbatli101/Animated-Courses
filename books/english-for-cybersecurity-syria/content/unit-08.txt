_80
@NUM 100
1. Read: "Root cause logic explains the relationship between an action and the result expected from it. It shows how an action is supposed to remove a cause. For example, if we log the report on the day it arrives, the log is complete. If the log is complete, the incident can be closed at once. If incidents are closed at once, sections stop chasing. If sections stop chasing, the function has time for the work itself. Root cause logic helps staff understand the path from one action to the long-term result."
