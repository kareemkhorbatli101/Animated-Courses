@INSTR Read about root cause logic.
_80
@NUM 100
1. Read: "Root cause logic explains the relationship between an action and the result expected from it. It shows how an action is supposed to remove a cause. For example, if we log the report on the day it arrives, the register is complete. If the register is complete, the booking can be closed at once. If bookings are closed at once, agencies stop chasing. If agencies stop chasing, the office has time for the work itself. Root cause logic helps staff understand the path from one action to the long-term result."
