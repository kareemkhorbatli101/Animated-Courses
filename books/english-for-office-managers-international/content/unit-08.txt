@INSTR Read about root cause logic.
_80
@NUM 100
1. Read: "Root cause logic explains the relationship between an action and the result expected from it. It shows how an action is supposed to remove a cause. For example, if we register the post on the day it arrives, the file is complete. If the file is complete, the answer can be written at once. If answers are written at once, departments stop chasing. If departments stop chasing, the office has time for the work itself. Root cause logic helps staff understand the path from one action to the long-term result."
            According to the text, does having clear root cause logic eliminate administrative risk?
