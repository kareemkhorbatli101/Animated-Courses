# English for NGOs and International Organizations (A2) — International Edition

An exact structural twin of the Syrian A2 Student Book, transposed so that every
unit is set in a different non-English-speaking country.

The source is the largest book in this series so far: ten units of forty-one
exercises, a 1,718-element answer key and a fifty-one-track audio appendix —
5,455 elements and 64,824 words across 264 tables.

### The exercise vocabulary

Four hundred and six exercises are built from a small set of body shapes:

| shape | how it is drawn |
| --- | --- |
| Matching | `Column A` + an N×3 table, `Column B` + an N×2 table |
| Multiple choice | an `F8F8F8` passage in a blue box, then bold numbered stems at 360 with `○ A)` … options at 720 |
| Classification | a bold blue `Categories:` head, `E6F3FF` category lines at 720, a bold blue `Classify each item:` head, then items at 720 with a ruled blank |
| Vocabulary fill | bold numbered lines at 360, the blank underlined on `F5F5F5` |
| Completion table | a `D6E8FF`-headed grid with `F0F0F0` cells to complete, then a `Choices:` box |
| Discussion | arrow-bulleted `ListParagraph` questions at 360 |

| Writing | a `📝 Write your response below:` prompt and a ten-row ruled frame |
| Pronunciation | a right-aligned `F0F0F0` audio chip, then the instruction box |

## 2 · The transposition

The source is set entirely in Syria. The twin moves each unit to a different
non-English-speaking country, across Asia, Africa, Latin America and the Middle
East, and keeps every structural feature of the source.

| unit | country | setting | focus |
| ---: | --- | --- | --- |
| 1 | **Nepal** | Kathmandu | what an NGO is, types, purposes |
| 2 | **Guatemala** | Guatemala City | NGO careers, job titles, skills |
| 3 | **Kenya** | Nairobi | the UN system and international organizations |
| 4 | **Bangladesh** | Cox's Bazar | humanitarian response and relief |
| 5 | **Mali** | Bamako | the skills and qualities NGO work needs |
| 6 | **Cambodia** | Phnom Penh | project cycle basics |
| 7 | **Bolivia** | La Paz | community participation and consultation |
| 8 | **Mozambique** | Maputo | health and education programmes |
| 9 | **Indonesia** | Jakarta | sustainable development and the SDGs |
| 10 | **Jordan** | Amman | NGO communication and professional interaction |

Named staff, partner agencies and example organizations are drawn from each
unit's country and from the international system (UNHCR, UNICEF, WFP, OCHA, the
Red Cross and Red Crescent movement, MSF, Save the Children, Oxfam, CARE), so
every unit's cast is local and the book as a whole is global.

The A2 grammar syllabus is unchanged, unit by unit: present simple (U1),
present perfect (U2), comparatives (U3), past simple (U4), modals of ability and
obligation (U5), future forms (U6), conditionals (U7), passive (U8), countable
and uncountable quantifiers (U9), reported speech and polite forms (U10).

## 3 · Fidelity criteria

The twin is held to the source on all of the following. Each is checked by a
script in `qa/`, not by eye.

1. Same element count in reading order, section by section.
2. Same paragraph style, shading, border colour, border weight and border sides.
3. Same indent, left and right.
4. Same `before`, `after` and `line` spacing on every paragraph.
5. Same page breaks, in the same places.
6. Same list membership and list format.
7. Same run structure inside every paragraph: bold, italic, underline, colour,
   size, shading, and where the text is split between runs.
8. Same table count, row count, cell count and column widths.
9. Same per-part bar colour and per-part instruction-box fill.
10. Same 41-exercise template, part by part, in every unit.
11. Same exercise naming scheme (`<Part>: <Title>`).
12. Same matching-table geometry: N×3 for Column A, N×2 for Column B.
13. Same multiple-choice shape: passage, bold stem, four `○` options.
14. Same classification shape: categories block, then items with ruled blanks.
15. Same completion-grid shading and the same `Choices:` box beneath it.
16. Same number of audio chips, track heads, writing frames and ruled lines.
17. Same 🔊 and 📝 counts.
18. Same blank-spacer count.
19. Same female- and male-voice line counts.
20. Same audio-track numbering and the same track-to-exercise mapping.
21. Word count within 2 % overall and within 3 % in every section.
22. Per-answer length parity in Appendix B.
23. Page count within one page, and the same section opening pages.

## 4 · The decoded design system

| element | how it is drawn |
| --- | --- |
| Page | A4 portrait, margins 1701 / 850 / 1701 / 1134 twips, grey `808080` page border |
| Header | Title, centred, `666666` 9 pt, rule under |
| Footer | `Page N of M` live fields, centred, rule over |
| `docDefaults` | empty — no default size, no default spacing |
| Unit head | `Heading1`, 18 pt bold `003366`, double `003366` rule under, page break before |
| Part bar | 16 pt bold white on the part colour, indent 200 both sides, page break before (not Warm Up) |
| Exercise head | `Heading3`, keepNext, 250 before / 150 after |
| Instruction box | 11 pt `3A3A3A` on the part fill, thin `3A3A3A` box, 1.25 line, indent 200 |
| Audio chip | right-aligned 9 pt `666666` on `F0F0F0`, keepNext |
| Play note | 16 pt `0066CC` 🔊 then 9 pt `666666`, on `E6F3FF` in a thin blue box |
| Reading passage | 11 pt on `F8F8F8`, thin `0066CC` box, indent 200 both sides |
| Panel | 11 pt on `F8F8F8`, indent 200 both sides, no border |
| MCQ stem | bold, indent 360, 150 before / 100 after |
| MCQ option | plain, indent 720, 50 after |
| Categories head | bold `0066CC` 11 pt, indent 360 |
| Category line | plain on `E6F3FF`, indent 720, 50 after |
| Classify item | plain, indent 720, 200 after, trailing underlined blank |
| Gap line | bold number, plain sentence, blanks underlined on `F5F5F5`, indent 360 |
| Arrow bullet | `→ ` then 11 pt, indent 360, bulleted list |
| Dialogue line | speaker bold in voice colour, body in the same colour, `CCCCCC` left rule, indent 720 |
| Script line | speaker bold in voice colour, body plain, on `F8FCFF`, indent 300 |
| Column head | `Column A` / `Column B`, plain, 100 after |
| Match table A | N×3, `F8F8F8` number cell, `FFFEF8` blank cell, `000000` box, `CCCCCC` inside |
| Match table B | N×2, `F8FFF8`, `000000` box, `CCCCCC` inside |
| Completion grid | `D6E8FF` header, white body, `F0F0F0` cells to complete, `auto` borders |
| Choices box | bold `1A56A0` head on `FFF9E6` with a `DDAA00` top rule, options at 420 |
| Writing frame | ten ruled rows, `666666` |
| Write prompt | `📝 Write your response below:` bold, 200 before / 150 after |
| Answer head | bold `0066CC` `Exercise N: `, then the title in body text, indent 360 |
| Question head | plain, indent 500, 100 before / 50 after |
| Answer block | on `F8FFF8`, `006600` left rule, indent 500 / 200 |
| Answer strip | 1×5 table, `FFFEF8`, `0066CC` box, `CCCCCC` inside |
| Track head | bold `8B00FF` track, bold black exercise, plain title, `F8FCFF`, `8B00FF` top rule |
| Code block | 11 pt on `F5F5F5`, indent 720 / 360 |
| Separator | dotted `CCCCCC` bottom rule, 200 after |

## 5 · Build

```
python3 build/compile.py                      # content/*.txt -> dist/…_A2.docx
NGO_SRC=<src.docx> python3 qa/check.py        # whole-document structural parity
python3 qa/spacing.py  <src.docx>             # every paragraph's full layout
python3 qa/runs.py     <src.docx>             # every paragraph's run formatting
python3 qa/unitdiff.py <src.docx> <twin.docx> "Unit 3:"
python3 qa/answers.py  <src.docx>             # per-answer parity in Appendix B
python3 qa/partial.py  <src.docx>             # progressive parity while writing
python3 qa/outline.py  <doc>                  # dump any document in reading order
```
